# COMBES_THOMAS Directory Index

This directory focuses on **Green's Function Decay**, **Combes-Thomas Bounds**, and **Core Mass Gap Theory**.

## Folder Structure

- **CORE_THEORY/**: Central theoretical documents, synthesis engines, and project highlights.
- **MAXWELL_GREEN/**: Files related to Davies-Maxwell theory and Green's function decay.
- **COMBES_THOMAS_BOUNDS/**: Specific files on Combes-Thomas estimates and exponential decay.
- **HELFFER_SJOSTRAND/**: Helffer-Sjostrand covariance and related techniques.
- **OS_REFLECTION_POSITIVITY/**: Reflection positivity, Osterwalder-Schrader reconstruction, and bridges to the mass gap.
- **RICCATI_RG/**: Renormalization Group flows, Riccati equations for curvature, and drift analysis.
- **EVIDENCE_SIMULATIONS/**: Simulations, numerical diagnostics, and evidence packs.
- **DUPLICATES/**: Backup and duplicate files (e.g., versions with (N)).
- **INDICES/**: Previous index files.

## Key Documents (In CORE_THEORY)

- `00_Project_Synthesis.md`: Main synthesis status.
- `01_block_convexity_engine.md`: Core mechanism for convexity propagation.
- `MG_Constructive_Mass_Gap_Pipeline.md`: The constructive pipeline for the mass gap.
