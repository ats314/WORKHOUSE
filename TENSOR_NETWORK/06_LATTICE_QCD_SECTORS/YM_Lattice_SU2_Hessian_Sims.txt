Lattice Simulations: SU(2) Wilson Action Hessian on a 2^4 Lattice
=================================================================

This file collects the code and results for the exact Hessian of the SU(2) Wilson lattice action at the trivial configuration, using JAX autodiff for a 2×2×2×2 lattice.

----------------------------------------------------------------------
1. Lattice and Variables
----------------------------------------------------------------------

We consider a 4D lattice with L = 2 sites per dimension:

    Sites: 2^4 = 16
    Directions: μ = 0,1,2,3 (4 directions)
    Gauge group: SU(2)

Each link is parameterized in the Lie algebra su(2) as:

    A^a_μ(x) for a = 0,1,2 (3 generators), μ = 0..3, x = lattice site.

We flatten all link algebras into a single vector v ∈ R^{16 × 4 × 3} = R^{192}.

----------------------------------------------------------------------
2. SU(2) Exponential and Wilson Action
----------------------------------------------------------------------

SU(2) algebra basis:

    sigma[0] = σ_x / 2
    sigma[1] = σ_y / 2
    sigma[2] = σ_z / 2

We define:

    su2_alg(a) = a_0 σ_x/2 + a_1 σ_y/2 + a_2 σ_z/2

Exponential:

    U = exp(A) with A = su2_alg(a).

In code (JAX):

    import jax
    import jax.numpy as jnp

    sigma = jnp.array([
        [[0,1],[1,0]],
        [[0,-1j],[1j,0]],
        [[1,0],[0,-1]]
    ], dtype=jnp.complex128) / 2.0

    def su2_alg(a):
        return a[0]*sigma[0] + a[1]*sigma[1] + a[2]*sigma[2]

    def su2_exp(a):
        A = su2_alg(a)
        trAA = jnp.real(jnp.trace(A.conj().T @ A))
        norm = jnp.sqrt(trAA + 1e-12)
        return jnp.cos(norm)*jnp.eye(2) + 1j*jnp.sin(norm)*A/norm

Lattice size:

    L = 2
    beta = 2.2

Flat/reshape helpers:

    def flat_to_links(v):
        return v.reshape((L,L,L,L,4,3))

The Wilson action:

    def wilson_action(v):
        links = flat_to_links(v)
        S = 0.0
        for x in range(L):
            for y in range(L):
                for z in range(L):
                    for t in range(L):
                        for mu in range(4):
                            for nu in range(mu+1,4):

                                xp = (x + (mu==0)) % L
                                yp = (y + (mu==1)) % L
                                zp = (z + (mu==2)) % L
                                tp = (t + (mu==3)) % L

                                xq = (x + (nu==0)) % L
                                yq = (y + (nu==1)) % L
                                zq = (z + (nu==2)) % L
                                tq = (t + (nu==3)) % L

                                U1 = su2_exp(links[x,y,z,t,mu])
                                U2 = su2_exp(links[xp,yp,zp,tp,nu])
                                U3 = su2_exp(links[xq,yq,zq,tq,mu]).conj().T
                                U4 = su2_exp(links[x,y,z,t,nu]).conj().T

                                Uplaq = U1 @ U2 @ U3 @ U4
                                S += (1 - 0.5*jnp.real(jnp.trace(Uplaq)))
        return beta * S

----------------------------------------------------------------------
3. Hessian via Autodiff
----------------------------------------------------------------------

We compute the Hessian H at v = 0 (all links = identity) using JAX’s nested Jacobian:

    H_fine_fn = jax.jacfwd(jax.jacrev(wilson_action))
    v0 = jnp.zeros((L**4 * 4 * 3,))
    H_fine = H_fine_fn(v0)
    H_np = np.array(H_fine)
    evals = np.linalg.eigvalsh(H_np)

This yields the full 192×192 Hessian.

Key result:

    Fine lattice smallest eigenvalues: [3.3, 3.3, 3.3, 3.3, 3.3, 3.3, 3.3, 3.3, 3.3, 3.3]
    Fine lattice largest eigenvalues:  [9.9, 12.1, 12.1, 12.1, 12.1, 12.1, 12.1, 12.1, 12.1, 12.1]

We observe:

- The Hessian is strictly positive definite.
- The minimum eigenvalues cluster at 3.3.
- The maximum eigenvalues around 12.1 indicate anisotropic stiffness.

Interpretation:

At the trivial configuration U = I, the SU(2) Wilson action is locally stable and strictly convex in all directions. The curvature floor is set by a combination of β and plaquette adjacency structure. The anisotropy arises from the coupling between different links via plaquettes.
