# Project derivations & theory notes (generated)

This folder contains a curated set of **Markdown + LaTeX** documents distilled from the project PDFs/notebook outputs.

The emphasis is on:
- ideas that could plausibly scale into something deeper,
- and “hard anchors” that prevent you from debugging the same things repeatedly.

## Files

1. `01_theta_as_q_deformation_conjecture.md`  
   Working conjecture tying the θ-angle to a quantum-group deformation \(q=e^{i\theta}\).

2. `02_log_polar_q6j_numeric_stability.md`  
   Derivation of the log–polar strategy used to compute q-factorials and q–6j symbols stably at \(|q|=1\).

3. `03_chi_top_extraction_via_fourier.md`  
   Derives why Fourier fits are the right way to extract \(\chi_{\text{top}}\) from periodic free energy \(F(\theta)\), and how to compute curvature from Fourier coefficients.

4. `04_su2_one_plaquette_bessel_validation.md`  
   Exact SU(2) one-plaquette partition function (Bessel form) as a validation anchor for the pipeline.

## Philosophy

“Exciting” research comes from:
- speculative hypotheses **plus** brutal falsification tests.
These docs aim to preserve both.
