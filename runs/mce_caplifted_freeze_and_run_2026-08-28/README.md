## What happened

| Stage | Result |
|---|---|
| `freeze` | **PASS** — contamination scan clean, self-test 47/47, geometry preflight 609 evaluations, both SHA-256 pins match (`FREEZE.json`) |
| `run` | started; **terminated by hand at 45:27 wall-clock with cluster 1 of 609 still incomplete** |

The run was not killed for misbehaving. It was killed because a finding
registered the same day makes completing it pointless for G3's live target:
the engine assembles every certificate coefficient through
`_exact_gamma_scalar` and carries no shape/band-point/Stage-3H output, so a
completed 609-sweep adjudicates the Γ-point scalar only — the quantity
already externally validated and already established (`Phi_C(0) = 0`,
off-axis suite) as structurally incapable of constraining `Delta_C`. See the
`FINDING: the marked-cluster engine emits the Gamma scalar only` check and
`sweep_cannot_decide_c2` under G3 in `ledger/gaps.yaml`.

## The cost numbers this run bought

- **Sealed baseline (pristine fork):** cluster 1 — the single support-size-1
  cluster, smallest of the 609; 474 are 3-face — exceeded **45 minutes**
  without completing. This turns the 2026-08-22 bound (">13.5 CPU-minutes,
  probe terminated") into a 3.4× larger one on a faster arithmetic stack.
- **Memoization fork** (`engine_perf.py`, sha256 `f067aa1e7d29ed75...`):
  memoizes `contract_link_partition` on its exact inputs and removes the
  per-call `repr()` provenance mappings (error-path diagnostics only; zero
  physics). It passes the engine's own self-test 47/47 (`selftest_perf.log`)
  and agrees exactly, Fraction-for-Fraction, with the pristine engine on
  sampled `haar_inner` evaluations (`probe_perf.log`). On the same cluster 1
  it was terminated at **12:14, also incomplete** — the memoization does not
  change the complexity class, because the exercised contraction inputs are
  largely distinct (py-spy showed the hot path still in fresh union-find
  work). This fork is likewise not vendored; `probe_perf.py` /
  `probe_equiv.py` regenerate the experiment.
- A 60-second py-spy sample of the live sealed process attributes ~100% of
  the time to `closure_matrices → haar_inner → contract_link_partition`,
  with >50% self-time in the pure-Python union-find and partition
  canonicalization (`find`/`union`/`canon`/`merge_classes`). The Gram fill
  of the first cluster's closure is the wall, before any resolvent algebra.

Together with `scripts/g3_local_sweep.py`'s census (474 of 609 are 3-face and
cost grows steeply with support), the sealed sweep is a months-class
computation on any current hardware — priced now against a blind scalar
confirmation only, not against C2.
