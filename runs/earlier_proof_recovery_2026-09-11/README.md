# Earlier proof recovery: retained evidence

11 September 2026. This run preserves seventeen original source/certificate
files and the receipts for a scan across the WORKHOUSE collection. The
[canonical derivation](../../docs/derivations/earlier-proof-recovery.md) and
[research handoff](../../docs/research/earlier-proof-discovery-2026-09-11.md)
state the resulting mathematics and its application boundaries.

- `source_manifest.json` maps original paths and SHA-256 digests to retained copies.
- `sources/` contains exact original bytes, including the two replayed instruments.
- `exact_controls.json` records fourteen fresh native exact controls. The first
  invokes the original singular-geometry engine, which reports 16/16 exact gates.
- `keyword_coverage.jsonl` resolves each of the 6,882 distinct keyword-hit contents
  to native NOTE identities, retaining digest, primary path, extraction method,
  prior identities and initial disposition.
- `coverage_summary.json` fixes that digest set and its coverage counts.
- `discovery_receipts/` preserves the prior audit's report, coverage, limitations,
  selected checks and scripts unchanged. Their earlier wording records the
  pre-integration state and does not describe the updated graph.
- `start-brief.json` is the unchanged starting saved graph snapshot.
- `SHA256SUMS` seals the logical bytes of every file in this run.

This package registers twenty-one result records and twenty-seven derivation
statements (twenty-one result statements, four open extensions and two rejected
historical formulas). The B6 campaign is historical numerical evidence: its
original eigensolver was not rerun. No archive-import verdict, keyword hit,
finite example or source hash is a whole-statement proof certificate.

The original scan searched 15,227 distinct texts among 192,937 listed physical
paths, including supported archive members. Its frozen COVERAGE receipt lists
runtime exclusions, 57 traversal-error lines, invalid fixtures, unsupported
formats, lack of OCR and lack of Git-object-history traversal. Accounting for
all keyword hits does not assert semantic review of the entire collection.

The native source-review validator now accepts registered RESULT, DERIV and CHK
identities without executing the graph collector. Note edges preserve those
full identities while retaining legacy bare-constant behavior. Regression tests
exercise missing identities, source-byte pins and the coverage-to-node mapping.
