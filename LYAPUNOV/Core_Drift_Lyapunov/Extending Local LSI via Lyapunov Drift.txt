# **1. Generator (L_\Lambda) on the lattice**

On a link (\ell), right-invariant vector fields (X^a_\ell) (with (a=1,\ldots,\dim G)) satisfy:

[
\nabla f(U) = \sum_{\ell,a} (X^a_\ell f)(U), X^a_\ell,
]

[
\Delta f = \sum_{\ell,a} X^a_\ell X^a_\ell f.
]

Thus the Langevin generator is:

[
\boxed{
L_\Lambda f
===========

## \sum_{\ell,a} X^a_\ell X^a_\ell f

\sum_{\ell,a} (X^a_\ell S_\Lambda) (X^a_\ell f).
}
]

For Yang–Mills:

[
S_\Lambda = S_W + S_{\mathrm{add},\Lambda},
]
[
X^a_\ell S_W = \beta \sum_{p\ni \ell} X^a_\ell \left(1-\frac1N \mathrm{Re},\mathrm{Tr},U_p\right).
]

# **2. Derivative of the Lyapunov function**

[
W_\Lambda(U)= 1 + \sum_p \Phi(r_p^2).
]

Let:

[
z_p = r_p^2 = d_G(U_p,e)^2.
]

Then by chain rule:

[
X^a_\ell W_\Lambda
==================

\sum_{p\ni \ell} \Phi'(z_p), X^a_\ell(z_p).
]

We need (X^a_\ell(z_p)).
Since (z_p = d_G(U_p, e)^2), in exponential coordinates:

[
U_p = \exp(X_p),
\qquad
z_p = |X_p|^2.
]

So for small-field expansions (SAFE region):

[
X^a_\ell(z_p)
=============

2 ,\langle X_p, X^a_\ell X_p\rangle.
]

Outside SAFE, the exact derivative is via pushforward along the plaquette map:

[
X^a_\ell(z_p)
=============

2, \langle \log(U_p),, d\log(U_p)[ X^a_\ell U_p ]\rangle.
]

This is **exact**, no approximations.

Thus:

[
\boxed{
X^a_\ell W_\Lambda
==================

\sum_{p\ni \ell}
2,\Phi'(z_p),\langle \log(U_p),, d\log(U_p)[ X^a_\ell U_p ] \rangle.
}
]

# **3. Second derivative term: (\Delta W_\Lambda)**

[
\Delta W_\Lambda
================

# \sum_{\ell,a} X^a_\ell X^a_\ell W_\Lambda

\sum_{\ell,a}\sum_{p\ni \ell}
X^a_\ell!\left( \Phi'(z_p),X^a_\ell z_p\right).
]

Expand:

[
X^a_\ell X^a_\ell W_\Lambda
===========================

\Phi''(z_p),(X^a_\ell z_p)^2
;+;
\Phi'(z_p), X^a_\ell X^a_\ell z_p.
]

Thus the total Laplacian term:

[
\boxed{
\Delta W_\Lambda
================

\sum_p
\left[
\Phi''(z_p)\sum_{\ell\in p,a}(X^a_\ell z_p)^2
;+;
\Phi'(z_p)\sum_{\ell\in p,a} X^a_\ell X^a_\ell z_p
\right].
}
]

This term has **two pieces**:

### **(i) The square-gradient term**

[
\Phi''(z_p)(X^a_\ell z_p)^2
]
This is benign because (\Phi'') is bounded (linear truncation makes it decay as (r^{-3/2})).

### **(ii) The geometric Laplacian term**

[
\Phi'(z_p), X^a_\ell X^a_\ell z_p
]
This contains the group Ricci curvature (positive!) and the structure of the plaquette embedding.
It is a **major source of negative drift**.

# **4. Drift term: (-\langle\nabla S_\Lambda,\nabla W_\Lambda\rangle)**

Using:

[
\langle\nabla S_\Lambda,\nabla W_\Lambda\rangle
===============================================

\sum_{\ell,a} (X^a_\ell S_\Lambda)(X^a_\ell W_\Lambda)
]

and our expression from Section 2:

[
X^a_\ell W_\Lambda
==================

\sum_{p\ni \ell} \Phi'(z_p), X^a_\ell z_p.
]

Thus:

[
\boxed{
\langle\nabla S_\Lambda,\nabla W_\Lambda\rangle
===============================================

\sum_{\ell,a}\sum_{p\ni \ell}
\Phi'(z_p) (X^a_\ell S_\Lambda)(X^a_\ell z_p).
}
]

For YM:

[
X^a_\ell S_W
============

# \beta \sum_{q\ni\ell} X^a_\ell!\left(1-\frac1N\mathrm{Re}\operatorname{Tr}U_q\right)

-,\beta\sum_{q\ni\ell} \langle Y^a_\ell, \log U_q\rangle

* \text{higher-order terms},
  ]

with (Y^a_\ell) a right-invariant generator pushed through the plaquette orientation.

Thus outside SAFE (large plaquettes):

[
X^a_\ell S_W \sim c_1 r_q,
\quad
X^a_\ell z_p \sim c_2 r_p,
]

so the contribution behaves like:

[
-,\langle\nabla S_\Lambda,\nabla W_\Lambda\rangle
;\sim;
-,\sum_p \Phi'(z_p), r_p^2.
]

Since (\Phi'(z_p)) is **linear in (r_p)** for large field (due to truncation), this gives:

[
-,\langle\nabla S_\Lambda,\nabla W_\Lambda\rangle
;\sim;
-,\text{const},
\sum_p \left(r_p^2 + r_p\right),
]
i.e. a **strong negative drift**.

L_\Lambda W_\Lambda

Every term is explicit and geometric.

# **6. Where the *negative drift* comes from**

The drift inequality requires:

[
L_\Lambda W_\Lambda \le -\alpha W_\Lambda + \beta\mathbf{1}_K.
]

The terms giving the negative sign are:

### **(i) The Wilson-action term**

[
-(X^a_\ell S_\Lambda)(X^a_\ell z_p)
]
Outside SAFE:
[
X^a_\ell S_W \sim c r_p,\qquad
X^a_\ell z_p\sim c r_p,
]
thus:
[
-(X^a_\ell S_W)(X^a_\ell z_p) \sim - c r_p^2.
]

### **(ii) The Haar Ricci curvature term (hidden inside (X^a_\ell X^a_\ell z_p))**

The group Ricci curvature contributes **positive second derivative of the squared distance**, giving:
[
X^a_\ell X^a_\ell z_p \approx
2\dim G + O(r_p)
]
i.e., a **restoring force** even when the Wilson part weakens.

Thus:

[
L_\Lambda W_\Lambda(U)
\approx

* \sum_p c_1 r_p^2

- \sum_p c_2 r_p
- \sum_p c_3
  ]

with constants (c_i) independent of (\Lambda).

When (r_p) is large, (-c_1 r_p^2) dominates, ensuring **uniform negative drift**.

Inside SAFE, everything is bounded, so one absorbs all terms into (\beta\mathbf{1}_K).

# **7. Where the remaining difficulty is (one place!)**

Every term in (LW_\Lambda) is controlled **except one**:

### 🔥 The uncontrolled term that blocks the proof:

[
\sum_{p} \Phi'(z_p)\sum_{\ell\in p,a} X^a_\ell X^a_\ell z_p.
]

This contains the exact second derivative of the **distance-squared function** on (G) composed with the **plaquette map**, which has nontrivial nonlinearities.

To finish the proof, you must show:

[
X^a_\ell X^a_\ell z_p ;\ge; c_0
\quad\text{uniformly outside SAFE.}
]

This is believed to be true because:

* distance squared on a compact Lie group has **positive Laplacian** away from the cut locus,
* the plaquette map is smooth and locally Lipschitz,
* large-field configurations sit far from the cut-locus.

But no one has produced a lattice-uniform explicit bound.

This is the **only unsolved analytic obstruction**.
