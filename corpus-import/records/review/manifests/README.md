# manifests — MD5 manifests of external stores at survey time

One file per store-survey, named `<STORE>_MD5_<date>.txt`, produced during rule-11 sweeps (CLAUDE.md rule 11: MD5 manifest on every deposit/intake). These freeze what a store contained when surveyed — dedup and drift checks run against them. Current: `SIMULATIONS_MD5_2026-06-12.txt` (271 notebooks, F023).
