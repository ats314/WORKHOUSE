# theory/notes/

Mathematical notes and derivations that are **not yet promoted** to a citable theorem. Working material: reductions, route sketches, curvature corrections, shape-space explorations, folded-coefficient derivations.

Promotion path: a note that becomes settled and gets cited elsewhere moves to `theory/theorems/`; a note that turns out to be wrong stays here with a correction header rather than being deleted — a refuted route is information, and a recorded dead end is cheaper than a repeated one.

Nothing in this directory is status-bearing. Do not cite a note as established.
