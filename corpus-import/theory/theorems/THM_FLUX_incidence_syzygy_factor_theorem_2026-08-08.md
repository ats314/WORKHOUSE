## 3. Exact cage-annihilator theorem

### Theorem KAF — Laurent–Koszul cage-annihilator factorization

Let

\[
R(z)\in{\rm Mat}_{3\times3}(\mathcal A).
\]

Then

\[
R(z)\psi(z)=0
\]

if and only if there exists

\[
C(z)\in{\rm Mat}_{3\times3}(\mathcal A)
\]

such that

\[
\boxed{
R(z)=C(z)S(z)
=-C(z)\widetilde N(z)^T.
}
\]

Define

\[
\mathcal J_\psi
:=
\left\{
C(z)S(z):
C(z)\in{\rm Mat}_{3\times3}(\mathcal A)
\right\}.
\]

Then the theorem is equivalently

\[
\boxed{
\{R\in{\rm Mat}_{3\times3}(\mathcal A):R\psi=0\}
=
\mathcal J_\psi.
}
\]

Thus \(\mathcal J_\psi\) is the **complete finite-range Laurent annihilator module** of the caged vector.

### Proof

The reverse implication follows immediately from \(S\psi=0\).

For the forward implication, consider one row

\[
r=(r_1,r_2,r_3)\in\mathcal A^3
\]

satisfying

\[
r_1v_2-r_2v_1+r_3v_0=0.
\tag{1}
\]

Reduce (1) modulo \((v_0)\). Since

\[
\mathcal A/(v_0)
\cong
\mathbb Q[z_1^{\pm1},z_2^{\pm1}]
\]

is a UFD and \(v_1=z_1-1\) and \(v_2=z_2-1\) are relatively prime there,

\[
r_1v_2=r_2v_1\pmod{v_0}
\]

implies that, modulo \(v_0\),

\[
r_1=v_1 a,
\qquad
r_2=v_2 a
\]

for one common \(a\). Lifting \(a\) to \(\mathcal A\), there exist \(b,c\in\mathcal A\) with

\[
r_1=v_1a-v_0b,
\qquad
r_2=v_2a-v_0c.
\]

Substituting into (1),

\[
v_0(-bv_2+cv_1+r_3)=0.
\]

Because \(\mathcal A\) is a domain,

\[
r_3=bv_2-cv_1.
\]

Therefore

\[
r
=
a(v_1,v_2,0)
+b(-v_0,0,v_2)
+c(0,-v_0,-v_1),
\]

so \(r\) is a row combination of \(S\).

Applying this independently to the three rows of \(R\) produces a Laurent-polynomial matrix \(C\) satisfying \(R=CS\). \(\square\)

## 4. The factor is not unique

The three generating rows of \(S\) obey the second Koszul relation

\[
v_0\,S_{1\bullet}
+
v_1\,S_{2\bullet}
+
v_2\,S_{3\bullet}
=0.
\]

Therefore \(C\) is not unique.

This is useful computationally: once an explicit residual kernel is available, the freedom generated by \((v_0,v_1,v_2)\) can be used to seek a factor \(C\) with minimal Laurent support, maximal symmetry, or a preferred cubical interpretation.

## 6. Hermitian corollary

For a finite-range Hermitian lattice operator, let \(\star\) denote transpose together with the Laurent involution \(z_j\mapsto z_j^{-1}\).

If

\[
R^\star=R
\]

and \(R\psi=0\), then Theorem KAF gives \(R=CS\). Taking \(\star\),

\[
\boxed{
R=S^\star C^\star.
}
\]

Hence a Hermitian quotient-trivial residual admits both a right syzygy factorization and a left adjoint-syzygy factorization.

This **does not** imply a two-sided local factorization

\[

\]

with Laurent-polynomial \(M\). That stronger divisibility statement remains separate.
