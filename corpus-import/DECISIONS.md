**#015 (2026-08-20) — Filenames are structured metadata; the corpus ships flat.** Alex: agents must get maximum information from a name, and the whole corpus will be uploaded **flat** to WORKHOUSE for a second agent to reorganize. Adopted `CLASS_TOPIC_descriptor[_vN][_YYYY-MM-DD].ext` (`NAMING_CONVENTION.md`), with `CLASS` and `TOPIC` as uppercase closed vocabularies and a lowercase descriptor, so parsing is unambiguous and `ls`/`grep` become structured queries. **Status is excluded from filenames by design** — it changes, and a stale status in a name reads as authoritative while being wrong, the same failure this corpus already documents in its "PROVEN" banners; status stays in `STATE.md`, the corpus evidence ledger, and `theory/DOC_GOV_chain_status_map.md`. 885 files renamed, 92% conformance, `README.md` and root governance deliberately exempt (GitHub renders README per directory; a README's topic is its path). Every rename recorded with MD5 in `records/RENAME_MANIFEST_2026-08-20.tsv`. Also built: `theory/DOC_FLUX_constants_index.md`, indexing all 214 exact rationals that are this corpus's true join keys (a gap the June-era `DOC_GOV_conventions.md` §3 table left completely open for the flux-band program), and `GITHUB/`, the regenerable flat mirror with a briefing and manifest for the receiving agent. `GITHUB/` is **generated output, never authored** — it is excluded from all index tooling, an exclusion added after it was caught double-counting the corpus.
