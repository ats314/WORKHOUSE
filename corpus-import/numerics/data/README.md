# numerics/data/

Numeric data products: CSV benchmark tables, `.npz` matrix caches, extrapolation plots, and compressed fixtures.

Includes the SU(N) glueball JPC benchmark tables, the `1⁺⁻` lattice spectrum extract, the high-N extrapolation plot, the shell-46 diagnostic scan, the SU(6) local class matrices, and the Y4 Stage-I authority fixture.

**Benchmark tables are external lattice data**, not products of this program's series. The `1/N²` extrapolation built from them is a *lattice-data extrapolation, not a from-series continuum mass* — the corpus is explicit about this and so should any document that cites these files be.
