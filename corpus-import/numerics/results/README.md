# numerics/results/

Write-ups of computed results — the human-readable companion to `numerics/certificates/`.

Each file should state, at minimum: what was computed, by which engine, against which gates, and at what evidence level (`Analytic` / `Cold-reproduced` / `Output-certified` / `Numerical` / `Record-backed`). A result write-up without a named engine and a gate outcome is `Prose-only` and cannot be cited.
