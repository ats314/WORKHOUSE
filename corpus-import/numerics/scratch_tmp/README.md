# numerics/scratch_tmp/

Scratch working space, moved from the old root-level `tmp/`. Holds PDF page renders, a Y4 SOS reproduction directory, and loose intermediate JSON.

**Nothing here is authority, and nothing here should be cited.** Treat it as disposable: if something in this directory turns out to matter, promote it to `numerics/certificates/`, `numerics/results/`, or the owning campaign — and do it in the pass that discovers it, not later.

Use this directory (or the session scratchpad) for zip extraction and intermediate output, so that neither the tree root nor a curated directory accumulates working files.
