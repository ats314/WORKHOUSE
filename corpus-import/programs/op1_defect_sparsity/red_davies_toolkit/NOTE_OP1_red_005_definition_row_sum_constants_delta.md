Definition (row‑sum constants for \Delta_1)

Let \Delta_1:=d_1^*d_1 act on \ell^2(E(\Lambda);\mathfrak g) (block matrix with \mathfrak g-endomorphism entries). Define
C_0(\Delta_1)\;:=\;\max_{b\in E(\Lambda)}\ \sum_{\substack{\tilde b\in E(\Lambda)\\ \tilde b\neq b}}
\big|(\Delta_1)_{b\tilde b}\big|_{\mathrm{op}}.
\tag{9.DG.C0}
Equivalently, for L_\Lambda=\alpha\Delta_1,
B_0(L_\Lambda)\;:=\;\max_b\sum_{\tilde b\neq b}\big|(L_\Lambda)_{b\tilde b}\big|_{\mathrm{op}}
=\alpha\,C_0(\Delta_1).
\tag{9.DG.B0}
