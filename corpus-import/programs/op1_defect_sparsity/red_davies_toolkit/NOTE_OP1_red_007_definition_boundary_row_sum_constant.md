Definition (boundary row‑sum constant)

Fix b' and \phi=\phi_{b'}(b)=\mathrm{dist}_E(b,b'). Define
C_\partial(\Delta_1)\;:=\;\sup_{b'}\ \max_{b}\
\sum_{\substack{\tilde b\neq b\\ |\phi_{b'}(b)-\phi_{b'}(\tilde b)|=1}}
\big|(\Delta_1)_{b\tilde b}\big|_{\mathrm{op}}.
\tag{9.DG.boundary}
Then C_\partial(\Delta_1)\le C_0(\Delta_1), often strictly.
