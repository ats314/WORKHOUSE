# programs/hodge_haar_krylov/

The Haar-electric resolvent / Krylov / Feshbach line — the operator-theoretic approach to the same spectral problem, distinct from the marked-cluster combinatorics in `hodge_o4_adjudication/`.

Three sub-lines:

- **Haar electric resolvent** — `HODGE–HAAR_ELECTRIC_RESOLVENT_ENGINE_v0_6`, `Hodge_Haar_Electric_Resolvent_v06c`, plus the explicit-intertwiner (`v04`) and mixed-determinant (`v05c`) notebooks.
- **Anchored-graph Krylov / Feshbach** — `Hodge_Anchored_Graph_Krylov_Production_v1`, `Hodge_Glueball_Feshbach_Krylov_Production_v2`.
- **Mass–string global/nested Q** — `Hodge_Mass_String_GlobalQ_Krylov_v5_A100`, `Hodge_Mass_String_NestedQ_Moment_v7_A100`, and the `hodge_mass_string_linked_cubic_v9*` / `hodge_glueball_globalQ_vacuum_character_v8` scripts.

Forensics and design notes for this line are in `records/audits/` — see `02-local-haar-electric.md`, `04-anchored-krylov-prototypes.md`, `05-globalq-mass-string.md`, `06-physicalq-q2.md`, `07-denominator-lift.md`.

**Status: prototype/exploratory.** Nothing in this directory is currently a status-bearing input to the corpus. Kept together because the line is coherent and may be revived for the uniform near-`Γ` estimate (corpus §15.3), which is an operator-theoretic question rather than a combinatorial one.
