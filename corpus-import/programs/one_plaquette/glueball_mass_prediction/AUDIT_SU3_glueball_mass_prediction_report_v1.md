# Blind lattice-data prediction of the SU(3) \(1^{+-}\) glueball mass

## Prediction

The SU(3) \(1^{+-}\) datum was withheld. A weighted fit

\[
\frac{m_{1^{+-}}(N)}{\sqrt{\sigma}}
=
m_\infty+\frac{c}{N^2}
\]

was performed using only the finite-rank continuum values at

\[
N=4,5,6,8,10,12.
\]

The quoted \(N=\infty\) number was excluded from the primary fit because it may
have been obtained from a global fit that used SU(3).

The blind prediction is

\[
\boxed{
\frac{m_{1^{+-}}(SU(3))}{\sqrt{\sigma}}
=
6.151\pm 0.266
}
\]

with components

\[
\sigma_\mathrm{fit}=0.079,
\qquad
\sigma_\mathrm{model}=0.254.
\]

The fitted large-\(N\) relation is

\[
\frac{m_{1^{+-}}(N)}{\sqrt{\sigma}}
=
(5.7408\pm 0.0315)
+
\frac{3.691\pm 0.925}{N^2}.
\]

Fit quality:

\[
\chi^2/\mathrm{dof}
=
0.677/4.
\]

## Unblinding

The uploaded modern SU(3) benchmark is

\[
\frac{m_{1^{+-}}}{\sqrt{\sigma}}
=
6.065\pm 0.040.
\]

The blind error is

\[
+0.086,
\]

or

\[
0.32\sigma
\]

using the combined prediction and lattice uncertainties.

The earlier value \(8.31\) is not the \(1^{+-}\) mass. In the supplied full
spectrum it is the SU(3) \(1^{--}\) ground state. The correct modern
\(1^{+-}\) target is \(6.065(40)\).

## Cross-channel model calibration

The same finite-\(N\ge4\) procedure was used to predict held-out SU(3) values
for every channel with at least four training ranks. The target \(1^{+-}\)
ground state was excluded from this calibration.

- all-channel RMS extrapolation error:
  \[
  0.226;
  \]
- \(C=-\) channel RMS extrapolation error:
  \[
  0.254.
  \]

The larger value was used as the model systematic.

## Independent Hamiltonian-limit comparison

The uploaded Hamiltonian-limit study reports

\[
r_0m_{1^{+-}}=7.17(17).
\]

Using the historical conversion \(r_0\sqrt{\sigma}=1.19\), this corresponds to

\[
\frac{m_{1^{+-}}}{\sqrt{\sigma}}
\approx
6.025\pm 0.143,
\]

consistent with both the blind prediction and the modern continuum result.

With the same historical scale convention \(r_0^{-1}=410(20)\,\mathrm{MeV}\),
the blind prediction becomes

\[
\boxed{
m_{1^{+-}}
=
3.00\pm 0.20\ \mathrm{GeV}
}
\]

before assigning any additional uncertainty to \(r_0\sqrt{\sigma}\).

## Scope

This is a genuine held-out **lattice-data prediction across gauge-group rank**.
It is not yet the desired analytic continuation of the exact strong-coupling
series. The exact theorem motivates the \(1/N^2\) large-rank correction and
identifies the channel, but the next required calculation remains a
same-normalization string-tension bridge that can predict the continuum mass
from the \(y\)-series itself.
