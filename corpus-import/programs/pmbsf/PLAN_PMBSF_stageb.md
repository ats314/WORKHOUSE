## 5. Decision tree after Stage B

```
Stage B.1 ($N_{\rm samples} = 1024$):
├── If cap $R^2 \ge 0.10$: cap predictor is tight; §J.6 has a clean numerical foundation.
│                            → Pursue (a) §J.6-refined analytic theorem, (b) Stage B.3 $\beta$-scan.
├── If cap $R^2 \in [0.05, 0.10]$: mixed; both noise and incompleteness contribute.
│                                    → Add $\rho_{\rm mean}$, $k_{\rm mean}$ to the predictor set.
└── If cap $R^2 \le 0.05$: cap mechanism is directional only, not predictive.
                          → Search for additional features (e.g., second-neighbor staples).

Stage B.4 ($L$-scan):
├── If headline ratios stable: uniformity in volume supported.
│                               → Strengthens §J.6-refined Theorem 1 hypothesis.
└── If headline ratios drift > 1.2: finite-volume artifact present.
                                   → Diagnose: is it the threshold-tuning or the block geometry?

Stage B.3 ($\beta$-scan):
├── If $C_Q(\beta)$ varies < 1.3 over [3.0, 4.5]: $\beta$-uniform Lemma Q hypothesis is supported.
│                                                  → Stage C: analytic derivation of $C_Q$ at large $\beta$.
└── If $C_Q(\beta)$ varies > 1.5: $C_Q$ is $\beta$-dependent.
                                   → Re-express Lemma Q with explicit $\beta$-dependence.
```

## 6. What Stage B will NOT settle

- The analytic theorems §J.6-refined and §R.1 themselves. Stage B is variance reduction and parameter coverage; it tightens or rebuts the empirical conjectures, but a theorem still needs to be proved.
- The §R.1 $\sqrt{qq'} \to qq'$ upgrade. This requires either an Eberle coupling-by-reflection argument adapted to small-density events, or a polymer expansion derived from spectral-gap data. No amount of additional Wilson MCMC will deliver it.
- Atypical-config control (pass-12 §K.5 caveat 4). Wilson MCMC samples typical configurations by construction; testing atypical-config bounds requires either (a) importance sampling, or (b) a deterministic Lyapunov argument on the path-integral measure.
