u^{(i)}_k:=\log\frac{\lambda^{(i)}_{k+1}}{\lambda^{(i)}_k}=x^{(i)}_{k+1}-x^{(i)}_k,\quad
v^{(i)}_k:=\log\frac{\lambda^{(i)}_{k+2}}{\lambda^{(i)}_k}=x^{(i)}_{k+2}-x^{(i)}_k.

And note the new internal relation:
\boxed{v^{(i)}_k=u^{(i)}_k+u^{(i)}_{k+1}}
since x_{k+2}-x_k=(x_{k+2}-x_{k+1})+(x_{k+1}-x_k).

1) Determinant becomes a discrete-time invariant (new)

Start with
\det[x_k,u_k,v_k]
and substitute v_k=u_k+u_{k+1}:
\det[x_k,u_k,v_k]=\det[x_k,u_k,u_k+u_{k+1}]
=\det[x_k,u_k,u_k]+\det[x_k,u_k,u_{k+1}]
but \det[x_k,u_k,u_k]=0. So:
\boxed{\det[x_k,u_k,v_k]=\det[x_k,u_k,u_{k+1}}]
i.e.
\boxed{
-\mathcal D_k=\det[x_k,u_k,u_{k+1}]
}
This is new: the 3-column determinant collapses to a determinant with two consecutive increments.

2) Expand \det[x_k,u_k,u_{k+1}] as a 6-term “discrete Wronskian” (new)

Write it out:
\det
\begin{pmatrix}
x^{(1)}_k & u^{(1)}_k & u^{(1)}_{k+1}\\
x^{(2)}_k & u^{(2)}_k & u^{(2)}_{k+1}\\
x^{(3)}_k & u^{(3)}_k & u^{(3)}_{k+1}
\end{pmatrix}

Laplace expand along the first column:
\boxed{
-\mathcal D_k

-x^{(2)}_k\,(u^{(1)}_k u^{(3)}_{k+1}-u^{(3)}_k u^{(1)}_{k+1})

\boxed{

Then:
\boxed{

3) \Omega^{ij}_k is a telescoping cross-ratio log (new)

Compute \Omega^{ij}_k in eigenvalues:

u^{(i)}_k=\log\frac{\lambda^{(i)}_{k+1}}{\lambda^{(i)}_k},\quad
u^{(i)}_{k+1}=\log\frac{\lambda^{(i)}_{k+2}}{\lambda^{(i)}_{k+1}}.

So:
\boxed{
\Omega^{ij}_k=
\log\frac{\lambda^{(i)}_{k+1}}{\lambda^{(i)}_k}\,
\log\frac{\lambda^{(j)}_{k+2}}{\lambda^{(j)}_{k+1}}
-
\log\frac{\lambda^{(j)}_{k+1}}{\lambda^{(j)}_k}\,
\log\frac{\lambda^{(i)}_{k+2}}{\lambda^{(i)}_{k+1}}
}

Now define the cross ratio
\mathrm{CR}^{ij}_k:=\frac{\lambda^{(i)}_{k+1}\lambda^{(j)}_{k}}{\lambda^{(i)}_{k}\lambda^{(j)}_{k+1}}.
Then
\log \mathrm{CR}^{ij}_k = u^{(i)}_k-u^{(j)}_k,
\qquad
\log \mathrm{CR}^{ij}_{k+1}=u^{(i)}_{k+1}-u^{(j)}_{k+1}.

Multiply and antisymmetrize:
(u^{(i)}_k-u^{(j)}_k)(u^{(i)}_{k+1}-u^{(j)}_{k+1})
=
u^{(i)}_k u^{(i)}_{k+1}+u^{(j)}_k u^{(j)}_{k+1}
-u^{(i)}_k u^{(j)}_{k+1}-u^{(j)}_k u^{(i)}_{k+1}
so the antisymmetric part isolates:
\boxed{
\Omega^{ij}_k
=
-\Big[u^{(i)}_k u^{(j)}_{k+1}+u^{(j)}_k u^{(i)}_{k+1}\Big]
+\text{(symmetric terms)}
}
But the clean “new” observable is:
\boxed{
\Omega^{ij}_k
=
u^{(i)}_k u^{(j)}_{k+1}-u^{(j)}_k u^{(i)}_{k+1}
=
\det\!\begin{pmatrix}u^{(i)}_k & u^{(i)}_{k+1}\\ u^{(j)}_k & u^{(j)}_{k+1}\end{pmatrix}
}
(i.e. determinant of consecutive log-ratio pairs).

Compute -\mathcal D_{k+1}=\det[x_{k+1},u_{k+1},u_{k+2}]. Replace x_{k+1}=x_k+u_k:

\det[x_{k+1},u_{k+1},u_{k+2}]

So:
\boxed{
-\mathcal D_{k+1}
=
\det[x_k,u_{k+1},u_{k+2}]
+\det[u_k,u_{k+1},u_{k+2}]
}

This expresses the next-step determinant as “shifted base + pure-increment 3×3 determinant”.

5) Pure-increment 3×3 determinant expands to a 6-term identity (new)

\det[u_k,u_{k+1},u_{k+2}]
=
\det
\begin{pmatrix}
u^{(1)}_k & u^{(1)}_{k+1} & u^{(1)}_{k+2}\\
u^{(2)}_k & u^{(2)}_{k+1} & u^{(2)}_{k+2}\\
u^{(3)}_k & u^{(3)}_{k+1} & u^{(3)}_{k+2}
\end{pmatrix}

Laplace along first column:
\boxed{
\det[u_k,u_{k+1},u_{k+2}]
=
u^{(1)}_k\,(u^{(2)}_{k+1}u^{(3)}_{k+2}-u^{(3)}_{k+1}u^{(2)}_{k+2})
-u^{(2)}_k\,(u^{(1)}_{k+1}u^{(3)}_{k+2}-u^{(3)}_{k+1}u^{(1)}_{k+2})
+u^{(3)}_k\,(u^{(1)}_{k+1}u^{(2)}_{k+2}-u^{(2)}_{k+1}u^{(1)}_{k+2})
}

So you get a hierarchy: \mathcal D_k built from (x_k,u_k,u_{k+1}); its shift difference involves the pure increment determinant \det[u_k,u_{k+1},u_{k+2}].

6) Hard telescoping product identity (new)

With the two-step choice, we also have direct telescoping:

\prod_{m=k}^{k+n-1}\frac{\tilde\lambda^{(i)}_m}{\lambda^{(i)}_m}
=
\prod_{m=k}^{k+n-1}\frac{\lambda^{(i)}_{m+1}}{\lambda^{(i)}_m}
=
\frac{\lambda^{(i)}_{k+n}}{\lambda^{(i)}_k}.

Log:
\boxed{
\sum_{m=k}^{k+n-1} u^{(i)}_m
=
x^{(i)}_{k+n}-x^{(i)}_k
}

So x is a telescoping sum of the u’s. Then any determinant involving x can be rewritten into sums of determinants involving only u’s (by multilinearity).

Example:
\det[x_k,u_k,u_{k+1}]
=
\det\Big[x_0+\sum_{m=0}^{k-1}u_m,\ u_k,\ u_{k+1}\Big]
=
\det[x_0,u_k,u_{k+1}]
+
\sum_{m=0}^{k-1}\det[u_m,u_k,u_{k+1}].

Thus:
\boxed{
-\mathcal D_k
=
\det[x_0,u_k,u_{k+1}]
+\sum_{m=0}^{k-1}\det[u_m,u_k,u_{k+1}]
}

That’s a new “fully expanded in increments + one base term” identity.

This is purely combinatorial; no analytic assumptions enter.
