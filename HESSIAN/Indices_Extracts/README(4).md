# ProofPack Selection — Curated “Most Exciting” Extracts

This folder contains a curated set of markdown+LaTeX notes extracted and synthesized from the project files.
They focus only on items that (a) appear genuinely structurally interesting, and/or (b) connect proofs to simulations.

## Files

1. **01_operator_triad.md** — one operator in three guises (Hessian / Gibbs generator / heat flow) and why it matters.
2. **02_davies_combes_thomas_maxwell.md** — finite-range inverse decay (Combes–Thomas) and Davies improvements for the massive Maxwell Green kernel; plus simulation context.
3. **03_reflection_positivity_coarse_graining.md** — reflection positivity permanence under reflection-equivariant coarse graining and projective limits.
4. **04_simulation_certificates.md** — numerical certificates and the key printed outputs (drift decomposition, affine laplacian law, ratio certificates, blocking spectral obstructions).
5. **05_gauge_rigidity_bridge.md** — a speculative-but-testable gauge ↔ rigidity/topological mechanics bridge.

## Note

Some source datasets referenced in code (e.g. `decomp_Lsweep_results.npz`) are not included in this folder;
the code blocks are copied/summarized from project logs and are intended to reproduce the printed diagnostics when run with those artifacts.
