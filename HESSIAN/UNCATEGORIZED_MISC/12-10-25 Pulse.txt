Here’s a compact, self‑contained way to cast the multi‑scale Riccati inequality as a one‑parameter curvature flow and read off the (strictly) increasing lower eigenvalue—i.e., a dynamic route to a mass gap.

---

# Setup (generator + curvature operator)

* Let ( \mu \propto e^{-S},dx ) with generator (L=\Delta-\nabla S\cdot\nabla).

* Bakry–Émery curvature operator on gradients:
  [
  \mathcal{K} ;\coloneqq; \nabla^2 S ;+; \mathrm{Ric},
  ]
  acting on tangent vectors (or gradient fields) (v). Assume ( \mathrm{Ric}\ge 0) or incorporate it into (\nabla^2 S) if working on (\mathbb{R}^n).

* Let (H) denote the “physical” Hessian (curvature operator restricted to the gauge‑projected directions you care about). Write its spectral floor
  [
  \lambda_{\min}(t);=;\inf_{|v|=1},\langle v, H(t),v\rangle .
  ]

# One‑parameter flow (Riccati form)

Introduce a curvature flow on (H(t)) driven by a (local) coarse‑graining/transport semigroup that preserves the measure class and contracts gradients:
[
\partial_t H ;=; \Phi(H);-;H^2,
\qquad \text{with } \Phi(H)\succeq \kappa_0 I ;;(\text{uniform source}).
]

* The ( -H^2 ) term is the Riccati contraction (comes from differentiating ( \nabla P_t f ) along the flow and using (\Gamma_2)).
* The source ( \Phi(H) ) encodes fresh convexity injected by the step (e.g., Haar/entropy curvature, block‑integration Jacobians, or stabilizing counterterms). A minimal hypothesis that suffices below is ( \Phi(H)\succeq \kappa_0 I) for some (\kappa_0>0).

# Minimal eigenvalue evolution (scalar comparison)

By standard matrix comparison for Riccati flows,
[
\dot{\lambda}*{\min}(t);\ge; \kappa_0 ;-;\lambda*{\min}(t)^2.
]
Hence the scalar differential inequality
[
\dot{\ell}(t);=;\kappa_0-\ell(t)^2,\quad \ell(0)=\lambda_{\min}(0),
]
is a lower solution for (\lambda_{\min}). Solve explicitly:
[
\ell(t);=;\sqrt{\kappa_0},\tanh!\Big(\sqrt{\kappa_0},t + \operatorname{arctanh}\big(\tfrac{\ell(0)}{\sqrt{\kappa_0}}\big)\Big),
\qquad (|\ell(0)|<\sqrt{\kappa_0}).
]
Consequences:

* **Strict monotonicity:** if (\ell(0)\ge 0) and (<\sqrt{\kappa_0}), then (\dot{\ell}(t)>0) for all (t>0).
* **Uniform positive limit:** (\displaystyle \lim_{t\to\infty}\ell(t)=\sqrt{\kappa_0}).
* Therefore,
  [
  \lambda_{\min}(t);\ge;\ell(t);\nearrow;\sqrt{\kappa_0};>;0.
  ]

# Discrete multi‑scale (block/RG steps)

For a sequence of coarse‑graining maps indexed by (n) with per‑step time ( \delta t ) and the same lower source (\kappa_0),
[
H_{n+1};\succeq; H_n ;+; \delta t,(\kappa_0 I - H_n^2),
]
so the scalar floors obey
[
\lambda_{\min}^{(n+1)};\ge; \lambda_{\min}^{(n)} ;+; \delta t,\big(\kappa_0 - (\lambda_{\min}^{(n)})^2\big),
]
a monotone iteration converging to (\sqrt{\kappa_0}). This yields **scale‑uniform strict convexity** after finitely many steps and a **uniform spectral gap/LSI** via standard curvature→gap implications.

3. correlations decay exponentially with rate ( \ge \sqrt{\kappa_0}); hence a **strictly positive mass scale** emerges dynamically.

Here’s a compact, technical brief on a useful program: **upgrade a local LSI on a SAFE set to a global LSI** using a Lyapunov drift + local (uniform‑in‑volume) LSI + entropy/variance decomposition.

---

### Setup

* Probability measure ( \mu \propto e^{-V(x)},dx ) on a (product) manifold (M).
* SAFE region (K\subset M): you can prove a **local LSI** with constant (\rho_K>0), uniformly in volume (blocks/scales).
* Goal: global LSI ( \operatorname{Ent}_\mu(f^2) \le \tfrac{2}{\rho}\int |\nabla f|^2,d\mu ) with (\rho>0) independent of system size.

### Ingredients

1. **Lyapunov function** (W\ge 1) with drift:
   [
   LW \le -\alpha W + b,\mathbf{1}_{K} \quad (\alpha>0)
   ]
   for the Langevin generator (L=\Delta-\nabla V!\cdot!\nabla).
   This implies integrability/tail control (finite “escape functional”) and gives a Foster–Lyapunov bound.
2. **Local LSI on (K)**:
   [
   \operatorname{Ent}_{\mu_K}(g^2) \le \tfrac{2}{\rho_K}\int |\nabla g|^2,d\mu_K,
   ]
   uniformly over volumes/tiles (same (\rho_K)).
3. **Local‑to‑global decomposition** (patched entropy/variance): split (f) with a partition of unity ({\phi,1-\phi}) where (\phi) localizes to (K). Control
   [
   \operatorname{Ent}*\mu(f^2)
   ;\le;
   \underbrace{\operatorname{Ent}*{\mu}((\phi f)^2)}_{\text{local on }K}

   * \underbrace{\operatorname{Ent}*{\mu}(((1-\phi)f)^2)}*{\text{tails}}
   * \text{cross terms},
     ]
     and bound tail/cross terms via the Lyapunov weight (W) and a weighted Poincaré/LSI.

### Canonical theorem (skeleton)

Let (W\ge1) satisfy (LW\le -\alpha W + b,\mathbf{1}_{K}) and assume a uniform local LSI on (K) with constant (\rho_K). Then (\mu) satisfies a **global LSI** with
[
\rho ;\gtrsim; \min!\left{\rho_K,; \frac{\alpha}{1+\log!\int W,d\mu + C(b,\nabla \phi)}\right},
]
where (C) depends on the cutoff (\phi) (transition layer size) and geometric constants. The proof patches the local LSI with a weighted (Lyapunov) control of (f) outside (K), using Herbst/transport or Rothaus‑type lemma to absorb cross terms.
