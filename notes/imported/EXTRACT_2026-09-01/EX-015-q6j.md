## 1. Log-space q-Racah evaluator for U_q(su(2)) 6j symbols (algorithm + reference implementation)

`status: solid` · `kind: algorithm`

### Statement

Fix $q=e^{i\theta}$, $\theta\in\mathbb R$. Define the $q$-integer, $q$-factorial and $q$-triangle coefficient
$$[n]_q=\frac{q^{n}-q^{-n}}{q-q^{-1}}=\frac{\sin(n\theta)}{\sin\theta},\qquad [n]_q!=\prod_{k=1}^{n}[k]_q,\quad [0]_q!=1,$$
$$\Delta_q(a,b,c)=\sqrt{\frac{[a+b-c]_q!\,[a-b+c]_q!\,[-a+b+c]_q!}{[a+b+c+1]_q!}} .$$
For spins $j_1,\dots,j_6\in\tfrac12\mathbb Z_{\ge0}$ satisfying the four triangle conditions on $(j_1,j_2,j_3)$, $(j_1,j_5,j_6)$, $(j_4,j_2,j_6)$, $(j_4,j_5,j_3)$ (each: $|a-b|\le c\le a+b$ and $a+b+c\in\mathbb Z$), the $q$-Racah formula reads
$$\begin{Bmatrix} j_1&j_2&j_3\\ j_4&j_5&j_6\end{Bmatrix}_q=\Delta_q(j_1,j_2,j_3)\Delta_q(j_1,j_5,j_6)\Delta_q(j_4,j_2,j_6)\Delta_q(j_4,j_5,j_3)\sum_{t=t_{\min}}^{t_{\max}}(-1)^t\,\mathcal R(t),$$
$$\mathcal R(t)=\frac{[t+1]_q!}{[t-\alpha_1]_q!\,[t-\alpha_2]_q!\,[t-\alpha_3]_q!\,[t-\alpha_4]_q!\,[\beta_1-t]_q!\,[\beta_2-t]_q!\,[\beta_3-t]_q!},$$
$$\alpha_1=j_1+j_2+j_3,\ \alpha_2=j_1+j_5+j_6,\ \alpha_3=j_4+j_2+j_6,\ \alpha_4=j_4+j_5+j_3,$$
$$\beta_1=j_1+j_2+j_4+j_5,\ \beta_2=j_2+j_3+j_5+j_6,\ \beta_3=j_3+j_1+j_6+j_4,$$
$$t_{\min}=\max_i\alpha_i,\qquad t_{\max}=\min_k\beta_k .$$
**Algorithm (log-for-products / linear-for-sums).** Evaluate every product and quotient of $q$-factorials additively in $\log$-space, and perform the alternating $t$-sum in ordinary (linear) arithmetic on the exponentiated amplitudes. Concretely: cache $\log|[n]_q!|=\sum_{k\le n}\log|[k]_q|$ together with the sign $\operatorname{sgn}([n]_q!)=\prod_{k\le n}\operatorname{sgn}([k]_q)$; form $\log|\mathcal R(t)|$ as one numerator log minus seven denominator logs; multiply the signs together with $(-1)^t$; exponentiate each term separately and accumulate. **All spins are stored in doubled-integer form $A=2j$**, so that triangle admissibility becomes the exact integer test $|A-B|\le C\le A+B$ and $A+B+C$ even, and every factorial argument is the exact integer $(A+B-C)/2$ etc. This removes all floating-point parity bugs.

### Derivation

Why the log-space split is necessary and why it is exact.

(1) *Overflow.* $[n]_q!$ is a product of $n$ factors each of size up to $1/|\sin\theta|$; the Racah numerator $[t+1]_q!$ with $t_{\max}\le 4J_{\max}$ overflows IEEE double already for modest $J_{\max}$ (classically $(t+1)!$ overflows at $t\approx170$, and the $q$-deformed magnitudes are larger still for small $\theta$). Direct evaluation of $\mathcal R(t)$ as a ratio of separately-computed factorials therefore returns inf/inf.

(2) *The identity being used.* For nonzero reals $x_k$,
$$\prod_k x_k=\Big(\prod_k\operatorname{sgn}x_k\Big)\exp\Big(\sum_k\log|x_k|\Big).$$
Applying it to numerator and denominator of $\mathcal R(t)$ gives
$$\log|\mathcal R(t)|=\log|[t+1]_q!|-\sum_{i=1}^{4}\log|[t-\alpha_i]_q!|-\sum_{k=1}^{3}\log|[\beta_k-t]_q!|,$$
$$\operatorname{sgn}\mathcal R(t)=\operatorname{sgn}[t+1]_q!\cdot\prod_{i}\operatorname{sgn}[t-\alpha_i]_q!\cdot\prod_k\operatorname{sgn}[\beta_k-t]_q! .$$
So the log-space evaluation is *algebraically identical* to the direct product evaluation: it is a bookkeeping identity, not an approximation. The only thing that changes is the dynamic range. (This is exactly the argument made in `02_log_polar_q6j_numeric_stability(1).md` §6.)

(3) *Why the $t$-sum must stay in linear space.* The alternating sum $\sum_t(-1)^t\mathcal R(t)$ encodes genuine interference between recoupling channels; individual terms can exceed the total by many orders of magnitude. Any 'log-sum-exp'-style compression of the sum destroys the cancellation. The correct discipline is therefore: logs for the *multiplicative* stage, ordinary complex/real addition for the *additive* stage. The relevant conditioning number is
$$\kappa=\frac{\sum_t|\mathcal R(t)|}{\big|\sum_t(-1)^t\mathcal R(t)\big|},$$
and $\log_{10}\kappa$ is the number of decimal digits lost. Measured values are given in the constants field.

(4) *Prefactor.* $\log\Delta_q(a,b,c)=\tfrac12\big(\log[a+b-c]_q!+\log[a-b+c]_q!+\log[-a+b+c]_q!-\log[a+b+c+1]_q!\big)$, evaluated once per triangle and added into the exponent of every summand, so the $\exp$ is applied exactly once per term.

(5) *Sign handling.* $(-1)^t$ is an exact integer sign in the $2j$ encoding (because admissibility forces $\alpha_i,\beta_k$, hence $t$, to be integers). The corpus's alternative $(-1)^t=e^{i\pi t}$ for half-integer $t$ (`LogSpace_qRacah_6j (1).md` §4) is never needed once the $2j$ encoding is used; keeping $t$ integral is strictly better numerically.

(6) *Zeros / roots of unity.* If any $[k]_q=0$ (i.e. $k\theta\in\pi\mathbb Z$), then $[n]_q!=0$ for $n\ge k$. The implementation returns a sentinel (`None` / $-\infty$) so that a summand with a vanishing *denominator* factorial is skipped rather than producing $\exp(+\infty)$. This is the point where the naive complex-log version of the code fails; see the separate obstruction item.

Best source: `SIMULATIONS/02_q6j_racah_logspace.md` (formula + first Python), `SIMULATIONS/LogSpace_qRacah_6j (1).md` (log-magnitude/phase split), `SIMULATIONS/02_log_polar_q6j_numeric_stability(1).md` (the correctness-as-bookkeeping argument), and the executable ground truth `SIMULATIONS/q6j_low_spin_validation.py`. # q6j_logspace.py -- validated log-space U_q(su2) 6j evaluator (2j-integer encoding).
# Consolidated from SIMULATIONS/q6j_low_spin_validation.py + 02_q6j_racah_logspace.md,
# with the Delta_q square-root branch handled by explicit sign tracking (see obstruction item).
# Pure stdlib. Run the validation suite in the next item against it.
import math, cmath
from functools import lru_cache

def tri_admissible(A, B, C):          # A = 2j
    return (abs(A-B) <= C <= A+B) and ((A+B+C) % 2 == 0)

def sixj_admissible(A, B, C, D, E, F):
    return (tri_admissible(A,B,C) and tri_admissible(A,E,F)
            and tri_admissible(D,B,F) and tri_admissible(D,E,C))

def _tk(theta):                       # stable float cache key
    return float(f"{theta:.16e}")

@lru_cache(maxsize=None)
def qint(n, tk):
    """[n]_q = sin(n*theta)/sin(theta), q = exp(i*theta); -> n as theta -> 0."""
    if abs(tk) < 1e-16: return float(n)
    s = math.sin(tk)
    if abs(s) < 1e-30: return float(n)
    return math.sin(n*tk)/s

@lru_cache(maxsize=None)
def log_qfact_signed(n, tk):
    """(log|[n]_q!|, sign) ; None if n<0 or [n]_q! == 0 (root of unity)."""
    if n < 0: return None
    lm, sg = 0.0, 1
    for m in range(1, n+1):
        x = qint(m, tk)
        if abs(x) < 1e-30: return None
        lm += math.log(abs(x))
        if x < 0: sg = -sg
    return (lm, sg)

def _delta_args(A, B, C):
    return (A+B-C)//2, (A-B+C)//2, (-A+B+C)//2, (A+B+C)//2 + 1

def log_delta_signed(A, B, C, tk):
    """(log|Delta_q|, kind) with kind in {'real','imag'}; None if inadmissible/zero.
    'imag' means Delta_q^2 < 0, i.e. Delta_q is purely imaginary."""
    if not tri_admissible(A, B, C): return None
    lm, sg = 0.0, 1
    for n, s in zip(_delta_args(A, B, C), (+1, +1, +1, -1)):
        r = log_qfact_signed(n, tk)
        if r is None: return None
        lm += s*r[0]; sg *= r[1]
    return (0.5*lm, 'real' if sg > 0 else 'imag')

def q6j(A, B, C, D, E, F, theta):
    """{A/2 B/2 C/2 ; D/2 E/2 F/2}_q at q = exp(i*theta).
    Returns a float inside the positivity domain (all four Delta_q^2 > 0);
    otherwise a complex value carrying the i^{#negative Delta^2} factor."""
    if not sixj_admissible(A, B, C, D, E, F): return 0.0
    tk = _tk(theta)
    lm, nimag = 0.0, 0
    for tri in ((A,B,C), (A,E,F), (D,B,F), (D,E,C)):
        r = log_delta_signed(*tri, tk=tk)
        if r is None: return 0.0
        lm += r[0]
        if r[1] == 'imag': nimag += 1
    t = ((A+B+C)//2, (A+E+F)//2, (D+B+F)//2, (D+E+C)//2)
    u = ((A+B+D+E)//2, (B+C+E+F)//2, (C+A+F+D)//2)
    S = 0.0
    for k in range(max(t), min(u)+1):                 # linear-space alternating sum
        num = log_qfact_signed(k+1, tk)
        if num is None: continue
        ld, sg, ok = 0.0, num[1]*(-1)**k, True
        for a in [k-x for x in t] + [y-k for y in u]:
            d = log_qfact_signed(a, tk)
            if d is None: ok = False; break           # vanishing denominator factorial
            ld += d[0]; sg *= d[1]
        if ok: S += sg*math.exp(lm + num[0] - ld)     # one exp per term
    if nimag % 2: return complex(0.0, ((-1)**((nimag-1)//2))*S)
    return ((-1)**(nimag//2))*S

def qdim(A, theta):
    """quantum dimension d_j = [2j+1]_q = [A+1]_q"""
    return qint(A+1, _tk(theta))

def positivity_domain(Jmax, theta):
    """Sufficient condition that every [n]_q used is > 0 (see obstruction item)."""
    return 0 <= theta < math.pi/(4*Jmax + 1)

## 2. Four-independent-check validation suite for the q-6j kernel, with reproduced tolerances

`status: solid` · `kind: code`

### Statement

The suite establishes, for all $\binom{}{}$ admissible sextuples in a $2j$-box, four *mutually independent* correctness certificates for the log-space kernel $K$:

**(C1) Classical limit vs. an independent symbolic reference.** For every admissible $(A,\dots,F)$ with $A,\dots,F\le 2J_{\max}$, $\big|K(A,\dots,F;\theta{=}0)-\texttt{sympy.physics.wigner.wigner\_6j}(A/2,\dots,F/2)\big|\le \mathrm{tol}_1$.

**(C2) Deformed values vs. an independent high-precision numerical route.** For $\theta>0$, $|K(\cdot;\theta)-R_{\rm mp}(\cdot;\theta)|\le\mathrm{tol}_2$, where $R_{\rm mp}$ evaluates the *same* Racah formula by *direct products* (no logs, no complex arithmetic, no cancellation-hiding) in mpmath at $\texttt{mp.dps}=80$. C2 is independent of C1 because it exercises the deformation, and independent of the log-space code path because it uses no logarithms.

**(C3) Tetrahedral symmetry orbit.** Let $G$ be the group generated by (i) the $3!$ permutations of the three *columns* $\{(A,D),(B,E),(C,F)\}$ and (ii) the three involutions that swap top/bottom entries in exactly *two* columns. Then for every $g\in G$ with $g\cdot(A,\dots,F)$ still admissible, $|K(g\cdot x;\theta)-K(x;\theta)|\le \mathrm{tol}_3$. This is a genuinely independent check: it constrains the kernel using only representation theory, not any reference implementation.

**(C4) Quantum orthogonality (unitarity of the recoupling transform).** For fixed $A,B,C,D$,
$$\sum_{X}[X+1]_q\begin{Bmatrix}A&B&X\\ C&D&E\end{Bmatrix}_q\begin{Bmatrix}A&B&X\\ C&D&E'\end{Bmatrix}_q=\frac{\delta_{EE'}}{[E+1]_q},$$
the sum running over $X$ with $(A,B,X)$ and $(C,D,X)$ admissible, and $E,E'$ over $X$ with $(A,D,E)$ and $(C,B,E)$ admissible. Deviations $\le\mathrm{tol}_4$.

A fifth, negative, observation recorded in the suite's own comments and worth preserving: **the symmetry test must never assume a symmetry that leaves admissible space.** The author's original Stage-A test compared $\{1\,1\,1;\tfrac12\tfrac12\tfrac12\}$ with $\{\tfrac12\tfrac12\tfrac12;1\,1\,1\}$ and 'failed'; the second tuple is simply inadmissible ($\tfrac12+\tfrac12+\tfrac12\notin\mathbb Z$). The orbit generator therefore filters by `sixj_admissible` before comparing.

### Derivation

Design rationale, and what each check would catch.

- C1 catches: wrong Racah summation limits, wrong $\Delta$ normalisation, wrong overall sign convention, wrong parity/triangle masks. SymPy computes `wigner_6j` by an entirely different (exact rational + `sqrt`) route, so agreement to machine precision on ~3400 tuples is strong evidence.
- C2 catches: everything specific to the *log* code path -- overflow guards, sign accumulation, the $(-1)^t$ phase, the treatment of $[n]_q!=0$. Since $R_{\rm mp}$ multiplies factorials directly at 80 digits, it has no cancellation problem at low spin and is an honest oracle. Note that C2 with $\mathrm{tol}_2=5\times10^{-13}$ is a *tight* test: the measured worst error is $\sim4\times10^{-16}$, three orders inside tolerance.
- C3 catches: index-order bugs in which of the four triangles is fed to which $\Delta_q$, and index bugs in $\alpha_i,\beta_k$. Note that the orbit generated by {column permutations, two-column row swaps} has order dividing 24 but is often much smaller after restricting to admissible images; measured orbit sizes: $\{1\,1\,1;1\,1\,1\}$ has orbit size 1 (totally symmetric), $\{\tfrac12\tfrac12 1;\tfrac12\tfrac12 1\}$ has orbit size 3.
- C4 catches: normalisation errors that are invisible to C3 (a global constant multiplying every symbol passes all symmetry tests but fails orthogonality), and any error in the quantum dimension $[2j+1]_q$.

**Choice of test angle.** The suite uses $\theta=\pi/22$. The reason (given in the script header and quantified in the obstruction item) is that $\theta=\pi/(k+2)$ with $k$ *large relative to the spins* keeps $[n]_q>0$ for every $n$ that occurs, so all quantities stay real and no branch-cut ambiguity can hide a bug. For $J_{\max}=2$ the largest factorial argument is $n_{\max}=4J_{\max}+1=9$ and $9\cdot\pi/22=1.285<\pi$, so positivity holds with margin.

# (a) the 24-element tetrahedral orbit generator:
def permute_columns(tup, perm):
    A,B,C,D,E,F = tup
    cols = [(A,D),(B,E),(C,F)]
    cols_p = [cols[i] for i in perm]
    A2,D2 = cols_p[0]; B2,E2 = cols_p[1]; C2,F2 = cols_p[2]
    return (A2,B2,C2,D2,E2,F2)

def swap_rows_in_two_columns(tup, which):
    A,B,C,D,E,F = tup
    cols = [(A,D),(B,E),(C,F)]
    i,j = which
    cols[i] = (cols[i][1], cols[i][0])
    cols[j] = (cols[j][1], cols[j][0])
    (A2,D2),(B2,E2),(C2,F2) = cols
    return (A2,B2,C2,D2,E2,F2)

def symmetry_orbit(tup):
    from itertools import permutations
    ops = [ (lambda x,p=p: permute_columns(x,p)) for p in permutations([0,1,2]) ]
    ops += [ (lambda x,w=w: swap_rows_in_two_columns(x,w)) for w in [(0,1),(0,2),(1,2)] ]
    seen, frontier = set(), [tup]
    while frontier:
        x = frontier.pop()
        if x in seen: continue
        seen.add(x)
        for op in ops:
            y = op(x)
            if y not in seen: frontier.append(y)
    return seen

# (b) the quantum orthogonality check (C4), generalized by me to all A,B,C,D:
def test_orthogonality_general(A, B, C, D, theta, q6j, qdim, tri, tol=5e-12):
    es = [E for E in range(0, A+D+1) if tri(A,D,E) and tri(C,B,E)]
    xs = [X for X in range(0, A+B+1) if tri(A,B,X) and tri(C,D,X)]
    worst = 0.0
    for E in es:

## 3. Obstruction: the complex-log square root in $\Delta_q$ picks the wrong branch outside the positivity domain; exact safe region $(4J_{\max}+1)\theta<\pi$ and a sign-tracking fix

`status: solid` · `kind: obstruction`

### Statement

Let $q=e^{i\theta}$, $\theta\in(0,\pi)$, and let $K_{\mathbb C}$ be the log-space kernel implemented with *complex* logarithms, i.e. $\log[n]_q!:=\sum_{k\le n}\texttt{cmath.log}([k]_q)$ and $\log\Delta_q:=\tfrac12(\ell_1+\ell_2+\ell_3-\ell_4)$ (this is the implementation in `q6j_low_spin_validation.py` and in every markdown version in the corpus). Let $R_{\rm mp}$ be the direct-product reference which computes $\Delta_q=\texttt{sqrt}(\text{ratio})$ on the principal branch.

**(i) Positivity domain.** For $\theta\in(0,\pi)$, $[n]_q=\sin(n\theta)/\sin\theta>0$ for all $1\le n\le n_{\max}$ **iff** $n_{\max}\theta<\pi$. In the $q$-Racah formula with all spins $\le J_{\max}$ the largest factorial argument is $n_{\max}=t_{\max}+1\le 4J_{\max}+1$. Hence
$$\boxed{\ (4J_{\max}+1)\,\theta<\pi\ \Longrightarrow\ \text{every }[n]_q\text{ used is }>0.}$$
On this domain all $\Delta_q^2>0$, the symbol is real, and $K_{\mathbb C}=R_{\rm mp}$ to full double precision.

**(ii) Failure outside it.** Write $N_\Delta:=\#\{$negative $[k]_q$ factors in the numerator of $\Delta_q^2\}-\#\{$negative factors in the denominator$\}$. Then $\operatorname{sgn}\Delta_q^2=(-1)^{N_\Delta}$, while the complex-log accumulation yields $\log\Delta_q^2=\log|\Delta_q^2|+i\pi N_\Delta$ (each negative factor contributes exactly $+i\pi$, each negative denominator factor exactly $-i\pi$; **no reduction mod $2\pi$ is performed**). Halving gives $\Delta_q=|\Delta_q|\,e^{i\pi N_\Delta/2}$, whereas the principal square root gives $|\Delta_q|$ (if $N_\Delta$ even) or $i|\Delta_q|$ (if $N_\Delta$ odd). These agree iff $N_\Delta\equiv 0$ or $1\pmod 4$; for $N_\Delta\equiv 2,3\pmod 4$ they differ by an **overall sign** (never a magnitude). Consequently $K_{\mathbb C}$ can return exactly $-R_{\rm mp}$: measured relative error exactly $2.00$.

**(iii) Fix.** Replace complex logs by (log-magnitude, integer sign) pairs, and compute $\Delta_q$ as $\operatorname{sgn}$-aware: return `('real', 0.5*log|ratio|)` if $\operatorname{sgn}\Delta_q^2=+1$ and `('imag', 0.5*log|ratio|)` if $-1$; assemble the product of four $\Delta$'s as $i^{n_{\rm imag}}\exp(\sum\tfrac12\log|\cdot|)$. With this fix the kernel agrees with $R_{\rm mp}$ to $\le 1.3\times10^{-14}$ relative for every admissible tuple with $J_{\max}\le3$ at every $\theta\in\{0.1,0.3,0.5,0.8,1.0,1.2,2.0,2.5,3.0\}$.

**(iv) Level-$k$ corollary.** The standard root-of-unity choice $q=e^{i\pi/(k+2)}$ with spins truncated at $j\le k/2$ has $n_{\max}=2k+1$ and $(2k+1)\pi/(k+2)<\pi\iff k<1$. So the level-$k$ truncation angle **never** lies in the positivity domain for $k\ge1$; to test at $\theta=\pi/(k+2)$ with spins $\le J_{\max}$ one needs $k>4J_{\max}-1$. (This is exactly why the validation suite uses $\theta=\pi/22$, i.e. $k=20$, with $J_{\max}=2$.)

### Derivation

**Proof of (i).** For $\theta\in(0,\pi)$, $\sin\theta>0$, so $\operatorname{sgn}[n]_q=\operatorname{sgn}\sin(n\theta)$, which is $>0$ iff $n\theta\in(0,\pi)\pmod{2\pi}$. The set $\{n\theta:1\le n\le n_{\max}\}$ is increasing, so all lie in $(0,\pi)$ iff $n_{\max}\theta<\pi$. For the bound $n_{\max}\le 4J_{\max}+1$: in $2j$ encoding, $t_{\max}=\min\big(\tfrac{A+B+D+E}{2},\tfrac{B+C+E+F}{2},\tfrac{C+A+F+D}{2}\big)\le\tfrac{4\cdot 2J_{\max}}{2}=4J_{\max}$, and the largest factorial argument in the sum is $t+1$; the $\Delta_q$ arguments are at most $\tfrac{A+B+C}{2}+1\le 3J_{\max}+1$. $\square$

**Proof of (ii).** $\texttt{cmath.log}(x)=\log|x|+i\pi$ for real $x<0$ (principal branch, $+\pi$ not $-\pi$). Summing over the four factorial logs with signs $(+,+,+,-)$ gives $\log(\text{ratio})_{\rm accum}=\log|\text{ratio}|+i\pi N_\Delta$ with $N_\Delta\in\mathbb Z$ possibly $|N_\Delta|>1$. Multiplying by $\tfrac12$ and exponentiating: $|\Delta_q|e^{i\pi N_\Delta/2}$. The principal square root of a real ratio $\rho$ is $\sqrt{\rho}$ for $\rho>0$ and $i\sqrt{|\rho|}$ for $\rho<0$. Comparing: $e^{i\pi N_\Delta/2}$ equals $+1,\,i,\,-1,\,-i$ for $N_\Delta\equiv 0,1,2,3\pmod4$, while the principal value is $+1$ for $N_\Delta$ even and $+i$ for $N_\Delta$ odd. ## 4. Classical-limit error budget: $|\{6j\}_q-\{6j\}|\le C\,\theta^2 J_{\max}^{5/2}$, with $C_{\rm global}$ reproduced and the safe-region table

`status: conditional` · `kind: derivation`

### Statement

Let $q=e^{i\theta}$, $J_{\max}=\max_i j_i$, and assume the *uniformity regime* $|\theta|J_{\max}\ll1$ (so that no $[n]_q$ used changes sign; cf. the exact criterion $(4J_{\max}+1)|\theta|<\pi$).

**(a) $q$-integer expansion (solid, exact).** $[n]_q=\dfrac{\sin n\theta}{\sin\theta}=n\Big(1-\dfrac{(n^2-1)\theta^2}{6}+O(n^4\theta^4)\Big)$, hence $\big|[n]_q-n\big|\le C_1\theta^2n^3$ with $C_1=1/6$ asymptotically.

**(b) $q$-factorial expansion (solid, exact).** $\log[N]_q!=\log N!-\dfrac{\theta^2}{6}Q_N+O(\theta^4N^5)$ with $Q_N=\sum_{k=1}^{N}(k^2-1)=\dfrac{N(N+1)(2N+1)}{6}-N=\dfrac{N(N-1)(2N+5)}{6}$, so $Q_N=\tfrac13N^3+O(N^2)$ and
$$[N]_q!=N!\Big(1-\tfrac{\theta^2}{6}Q_N+O(\theta^4N^6)\Big),\qquad \big|[N]_q!-N!\big|\le C_2\,\theta^2N^3\,N!,\ \ C_2\to\tfrac1{18}.$$

**(c) Relative error of the symbol (solid, given (a),(b)).** Every $\Delta_q$ and every Racah summand is a fixed ratio of $q$-factorials with arguments $\le 4J_{\max}+1$, so each acquires a multiplicative factor $1+O(\theta^2J_{\max}^3)$; therefore
$$\frac{\{6j\}_q-\{6j\}}{\{6j\}}=O(\theta^2J_{\max}^3).$$

**(d) Absolute bound (conditional -- this is the step with a gap).** Insert an amplitude bound for the classical symbol. Using the Ponzano--Regge envelope $|\{6j\}|\le C_3J_{\max}^{-1/2}$ gives
$$\big|\{6j\}_q-\{6j\}\big|\ \le\ C\,\theta^2\,J_{\max}^{5/2}.$$
A cruder accounting that also charges the $O(J_{\max})$ length of the $t$-sum gives $C\theta^2J_{\max}^{7/2}$; the $5/2$ exponent is the version that matches the numerics.

**(e) Engineering inversion.** For a target tolerance $\varepsilon$, $\ \theta\le\sqrt{\varepsilon/(C_{\rm global}J_{\max}^{5/2})}=\sqrt{\varepsilon/C_{\rm global}}\;J_{\max}^{-5/4}$.

### Derivation

**(a).** $\sin x=x-\tfrac{x^3}{6}+O(x^5)$ gives $\sin(n\theta)=n\theta\big(1-\tfrac{n^2\theta^2}{6}+O(n^4\theta^4)\big)$ and $\sin\theta=\theta\big(1-\tfrac{\theta^2}{6}+O(\theta^4)\big)$. Dividing, $[n]_q=n\big(1-\tfrac{n^2\theta^2}{6}\big)\big(1+\tfrac{\theta^2}{6}\big)+O(n^5\theta^4)=n\big(1-\tfrac{(n^2-1)\theta^2}{6}\big)+O(n^5\theta^4)$. Hence $|[n]_q-n|/(\theta^2n^3)=\tfrac{n^2-1}{6n^2}\nearrow\tfrac16$, matching the corpus's numerical statement 'the ratio is numerically $\approx1/6$ over wide ranges'.

*Convention warning (both appear in the corpus and both are correct in their own convention).* With $[n]_q=\sin(n\theta)/\sin\theta$ the coefficient is $(n^2-1)/6$ (files 01, 03, 05, `03_q6j_classical_limit_error_bounds.md`, `YM_extract_04`). With the half-angle convention $[n]_q=\sin(n\theta/2)/\sin(\theta/2)$, i.e. $q=e^{i\theta}$ and $[n]_q=(q^{n/2}-q^{-n/2})/(q^{1/2}-q^{-1/2})$, the coefficient is $(n^2-1)/24$ (file `04_q6j_error_bound_safe_region.md`). They differ by $\theta\to\theta/2$; the numerical scans all use the first.

**(b).** $\log[N]_q!=\sum_{k=1}^N\log[k]_q=\sum_k\big[\log k+\log(1-\tfrac{(k^2-1)\theta^2}{6}+O(k^4\theta^4))\big]=\log N!-\tfrac{\theta^2}{6}\sum_{k=1}^N(k^2-1)+O(\theta^4N^5)$, using $\log(1-\epsilon)=-\epsilon+O(\epsilon^2)$ and requiring $\theta^2N^2\ll1$ for the expansion of each factor to be legitimate. [reconstructed] The closed form $\sum_{k=1}^N(k^2-1)=\tfrac{N(N+1)(2N+1)}{6}-N=\tfrac{N(N-1)(2N+5)}{6}$ is mine; the corpus only records $Q_N=O(N^3)$. This gives $C_2=\lim_N Q_N/(6N^3)=1/18$.

**(c).** Each of the four $\Delta_q$ is $\sqrt{\text{(3 factorials)}/\text{(1 factorial)}}$ with arguments $\le 3J_{\max}+1$; each of the seven denominator factorials in $\mathcal R(t)$ has argument $\le 4J_{\max}$. Multiplying $\le 12$ ratios each of the form $1+O(\theta^2 J_{\max}^3)$ preserves the relative size $O(\theta^2J_{\max}^3)$ (with a constant $\le 12$).

**(d) -- where it is only conditional.** Step (c) controls the relative error of *each summand*, but the Racah sum has cancellation: the sum can be far smaller than its largest term (measured $\kappa$ up to $5.6\times10^2$ at $\theta=0.02$, and unbounded on exact zeros). A relative bound on each term therefore does *not* imply a relative bound on the sum without an extra ingredient. The corpus (and I) close this gap by *assuming* an amplitude bound $|\{6j\}|\le C_3J_{\max}^{-1/2}$ for the classical symbol and converting relative to absolute. That $-1/2$ envelope is asserted, not proved, in the corpus; the honest status is 'conditional on a quantitative uniform Ponzano--Regge amplitude estimate'. The corpus is itself explicit about this (`05_q6j_Error_Budget_v2.md` §4: 'Appendix E assumes a conservative decay exponent $\alpha\ge1/2$').

**Empirical validation (my reproduction).** I re-ran the scan of `05_q6j_error_budget_safe_region.md` using the validated kernel. **Interval-arithmetic upgrade path (from `04_q6j_error_bound_safe_region.md` §5).** Because the safe region $J_{\max}\le4$, $|\theta|\le0.02$ contains only finitely many admissible sextuples (for $J_{\max}=4$, i.e. $2j\le8$, there are $\sim10^5$), a computer-assisted theorem is feasible: enumerate, evaluate both $\{6j\}_q$ and $\{6j\}$ in ball arithmetic (`mpmath.iv` or Arb), partition $\theta\in[-0.02,0.02]$ into subintervals, take the sup of the interval upper bounds on $R(\theta)=|\{6j\}_q-\{6j\}|/(\theta^2J_{\max}^{5/2})$. ## 5. q-Racah Doob transform: the transformed operator is a reversible birth-death chain, with $\pi\propto\psi_0^2$, gap $=E_1-E_0$, and an exact 1D Cheeger bracket

`status: solid` · `kind: theorem`

### Statement

Let $H\in\mathbb R^{(N+1)\times(N+1)}$ be symmetric tridiagonal (a Jacobi operator),
$$(Hf)_n=V_nf_n-a_nf_{n+1}-c_nf_{n-1},\qquad a_n,c_n\ge0,\ c_0=a_N=0,\ a_n=c_{n+1},$$
irreducible ($a_n>0$ for $0\le n\le N-1$). By Perron--Frobenius the ground eigenpair $H\psi_0=E_0\psi_0$ has $\psi_0(n)>0$ for all $n$. Set $D=\operatorname{diag}(\psi_0)$ and define the **Doob $h$-transform**
$$Q:=-D^{-1}(H-E_0I)D,\qquad\text{i.e. }Q_{ij}=-H_{ij}\frac{\psi_0(j)}{\psi_0(i)}\ (i\ne j),\quad Q_{ii}=-\sum_{j\ne i}Q_{ij}.$$
Then:

**(T1) $Q$ is a continuous-time Markov generator.** $Q_{ij}\ge0$ for $i\ne j$ (because $H_{ij}\le0$ off-diagonal and $\psi_0>0$) and $Q\mathbf1=0$ by construction. Moreover the diagonal built by row-sum-zero coincides with $-D^{-1}(H-E_0I)D$ on the diagonal, so no information is lost.

**(T2) $Q$ is a birth-death generator.** $Q_{n,n+1}=a_n\dfrac{\psi_0(n+1)}{\psi_0(n)}=:b_n$, $Q_{n,n-1}=c_n\dfrac{\psi_0(n-1)}{\psi_0(n)}=:d_n$, $Q_{nn}=-(b_n+d_n)$, all other entries $0$.

**(T3) Reversibility.** $Q$ is reversible with respect to $\pi_n\propto\psi_0(n)^2$: $\pi_nb_n=a_n\psi_0(n)\psi_0(n+1)=\pi_{n+1}d_{n+1}$.

**(T4) Spectral identification.** $\operatorname{spec}(Q)=\{-(E_k-E_0)\}_{k=0}^{N}$, so
$$m(N):=-\lambda_1(Q)=E_1(H)-E_0(H).$$

**(T5) Dirichlet form and Poincare constant.** $\mathcal E(f,f)=-\langle f,Qf\rangle_\pi=\sum_{n=0}^{N-1}\mathfrak c_n(f_{n+1}-f_n)^2$ with edge conductance $\mathfrak c_n=\pi_nb_n=a_n\psi_0(n)\psi_0(n+1)$, and $m(N)=\inf\{\mathcal E(f,f)/\operatorname{Var}_\pi(f):\pi(f)=0\}$.

**(T6) Exact 1D Cheeger constant and bracket.** With $\Pi_k=\sum_{n\le k}\pi_n$,
$$\Phi=\min_{0\le k\le N-1}\frac{\mathfrak c_k}{\min(\Pi_k,1-\Pi_k)},\qquad \frac{\Phi^2}{2}\le m(N)\le 2\Phi.$$

### Derivation

**(T1).** For $i\ne j$: $Q_{ij}=-H_{ij}\psi_0(j)/\psi_0(i)$. Off-diagonal entries of a Jacobi matrix with $a_n,c_n\ge0$ are $H_{n,n\pm1}\le0$, and $\psi_0>0$, so $Q_{ij}\ge0$. For the diagonal: $(D^{-1}(H-E_0)D\mathbf 1)_i=\psi_0(i)^{-1}\sum_j(H-E_0)_{ij}\psi_0(j)=\psi_0(i)^{-1}\big((H\psi_0)_i-E_0\psi_0(i)\big)=0$. So the similarity transform already has zero row sums, and defining $Q_{ii}$ by row-sum-zero reproduces it exactly. Positivity of $\psi_0$ is exactly the condition the code checks (`np.min(psi0) < tol -> invalid`).

**(T2).** Immediate from tridiagonality: $Q$ inherits the sparsity pattern of $H$.

**(T3).** $\pi_nb_n=\psi_0(n)^2\cdot a_n\dfrac{\psi_0(n+1)}{\psi_0(n)}=a_n\psi_0(n)\psi_0(n+1)$ and $\pi_{n+1}d_{n+1}=\psi_0(n+1)^2\cdot c_{n+1}\dfrac{\psi_0(n)}{\psi_0(n+1)}=c_{n+1}\psi_0(n)\psi_0(n+1)$. These agree because symmetry of $H$ forces $a_n=c_{n+1}$. Note the *simultaneous* content of this: the invariant measure of the Doob chain is the ground-state *density* $\psi_0^2$, which is the standard 'ground state transformation' of a Schrodinger operator. **Verified numerically:** $\max_{i,j}|(\operatorname{diag}(\pi)Q)_{ij}-(\operatorname{diag}(\pi)Q)_{ji}|=1.39\times10^{-17}$ at $N=10$, $q=0.95$.

**(T4).** $Q=-D^{-1}(H-E_0)D$ is similar to $-(H-E_0)$, so eigenvalues are $-(E_k-E_0)$; $E_0$ is the smallest so $0$ is the top eigenvalue and $-\lambda_1(Q)=E_1-E_0$. **Verified numerically:** at $N=8$, $q=0.95$, $E_1-E_0=0.09501591175632965$ and $-\lambda_1(Q)=0.09501591175632955$ (agreement to $10^{-16}$).

**(T5).** For a reversible chain, $-\langle f,Qf\rangle_\pi=\tfrac12\sum_{i\ne j}\pi_iQ_{ij}(f_i-f_j)^2$; in the birth-death case only nearest-neighbour pairs contribute, and each unordered pair $\{n,n+1\}$ appears twice, giving $\sum_n\pi_nb_n(f_{n+1}-f_n)^2$. The variational characterisation of the second eigenvalue of a self-adjoint operator on $\ell^2(\pi)$ gives the Poincare form.

**(T6).** In a birth-death chain any set $S$ can be replaced by a prefix without increasing $\Phi$, because the boundary flow of a union of intervals is the sum of the flows of its endpoints while $\pi(S)$ is additive; the minimiser is a single interval, and by symmetry a prefix $S_k=\{0,\dots,k\}$. For a prefix the boundary flow is a single edge: $\sum_{i\in S_k,j\notin S_k}\pi_iQ_{ij}=\pi_kb_k=\mathfrak c_k$. Cheeger's inequality for reversible chains then gives $\Phi^2/2\le m\le2\Phi$.

### Code

import numpy as np, math, numpy.linalg as la

def doob_transform(H, tol=1e-12):
    """Ground-state (Doob h-) transform of a symmetric Jacobi matrix.
    Returns (Q, eigenvalues_of_H, psi0_normalised, ok)."""
    evals, evecs = la.eigh(H)
    idx = np.argsort(evals); evals = evals[idx]; psi0 = evecs[:, idx[0]]
    if psi0.sum() < 0: psi0 = -psi0
    psi0 = np.abs(psi0)
    if np.min(psi0) < tol:                 # Perron positivity lost numerically
        return None, evals, psi0, False
    psi0 = psi0/psi0.sum()
    n = H.shape[0]; Q = np.zeros_like(H)
    for i in range(n):
        for j in range(n):
            if i != j and H[i, j] != 0:
                Q[i, j] = -H[i, j]*psi0[j]/psi0[i]
    Q[np.diag_indices(n)] = -np.sum(Q, axis=1)
    ok = (np.max(np.abs(np.sum(Q, axis=1))) < 1e-6
          and np.min(Q - np.diag(np.diag(Q))) >= -1e-10)
    return Q, evals, psi0, ok

def spectral_gap(Q, tol=1e-10):
    """m = -lambda_1(Q), the eigenvalue closest to 0 from below."""
    eig = np.sort(np.real(la.eigvals(Q)))
    neg = eig[eig < -tol]
    return 0.0 if neg.size == 0 else -neg[-1]

def cheeger(Q, psi0):
    """Exact 1D Cheeger constant Phi and the bracket Phi^2/2 <= m <= 2 Phi."""
    n = Q.shape[0]
    pi = psi0**2; pi = pi/pi.sum()
    Pi = np.cumsum(pi)
    cond = np.array([pi[k]*Q[k, k+1] for k in range(n-1)])     # edge conductances
    Phi = min(cond[k]/min(Pi[k], 1-Pi[k]) for k in range(n-1))
    return Phi, cond, pi

**Caveat.** T1--T6 are standard facts about ground-state transforms and 1D reversible chains; the corpus's contribution is assembling them for this family and verifying them. Nothing here is specific to $q$-Racah data -- it holds for any irreducible symmetric Jacobi matrix with nonpositive off-diagonals.

**Why it matters.** It reduces a spectral-gap question about a $q$-deformed operator to a *one-dimensional Poincare inequality* with an explicit, computable Cheeger constant. That is the difference between 'we measured a gap' and 'we can bound the gap from data we control': $\Phi$ is a bottleneck diagnostic that says exactly which edge kills the gap.

## 6. The q-Racah Doob toy gap model: reproduced tables, and a derivation that $m_\infty(q)=\tfrac34(1-q)+O((1-q)^2)$

`status: solid` · `kind: numerical_result`

### Statement

Define, for $n=0,\dots,N$ and parameters $q\in(0,1)$, $\alpha,\beta,\gamma,\delta$,
$$A_n^2=\frac{(1-\alpha q^{n+1})(1-\beta\delta q^{n+1})(1-\gamma q^{n+1})(1-\delta q^{n+1})}{(1-\delta q^{2n+1})(1-\delta q^{2n+2})}\ (n\le N-1),\quad A_N=0,$$
$$C_n^2=\frac{(1-q^{n})(1-\beta q^{n})(1-\gamma q^{n})(1-\alpha\delta q^{n})}{(1-\delta q^{2n})(1-\delta q^{2n+1})}\ (n\ge1),\quad C_0=0,$$
and let $H=H(N,q;\alpha,\beta,\gamma,\delta)$ be the symmetric tridiagonal matrix
$$H_{nn}=A_n^2+C_n^2,\qquad H_{n,n+1}=H_{n+1,n}=-C_{n+1}.$$
(Note: this is what the project's code actually builds -- see caveat.) Let $m(N,q)=E_1(H)-E_0(H)$ be the Doob gap of the previous item.

**(a) [reproduced] Finite-$N$ near-critical fit.** With $\alpha=\beta=\gamma=\delta=1$ and $m(q)=\min_{N\in\{4,6,8,10,12\}}m(N,q)$ over $q\in\{0.93,\dots,0.99\}$, the log-log fit $\log m=\nu\log(1-q)+c$ gives $\nu=0.9668221$, $e^c=1.3770$.

**(b) [derived here] Exact fixed-$N$ linear closure.** For each fixed $N$, $m(N,q)=\kappa(N)\,(1-q)+O((1-q)^2)$ as $q\uparrow1$, so the exponent is exactly $\nu=1$; the $0.9668$ is a finite-window curvature artefact.

**(c) [derived here] The thermodynamic limit exists and has an exact constant.** $m_\infty(q):=\lim_{N\to\infty}m(N,q)$ exists for every $q\in(0,1)$ (the limit is attained numerically once $N\gtrsim 60/(1-q)$), and
$$\boxed{\ m_\infty(q)=\tfrac34\,(1-q)+O\big((1-q)^2\big),\qquad E_0\to-\tfrac12 .}$$
More precisely, in the scaling variable $x=n(1-q)$ the operator converges to $-\varepsilon^2t(x)\partial_x^2+V(x)$ with $t(x)=\tanh(x/2)$, $V(x)=-2t(x)(1-t(x))$, whose harmonic approximation at the well bottom gives $E_k=-\tfrac12+(2k+1)\tfrac{3\varepsilon}{8}$, $\varepsilon=1-q$.

**(d) [reproduced] Uniform-in-$N$ gap (the corpus's 'toy confinement criterion').** $\inf_Nm(N,q)>0$ for each fixed $q<1$: numerically $m(N,q)$ saturates, e.g. $m_\infty(0.90)=0.0732299$, $m_\infty(0.93)=0.0516794$, $m_\infty(0.95)=0.0370960$.

### Derivation

**(a) Reproduction.** I ran the code of `04_qRacah_Doob_MassGap_Toy_v2.md` verbatim. Every entry of the published table is reproduced to all six quoted digits, and the fitted $\nu=0.9668221488$ matches the corpus's $0.9668203676$ / $0.9668$ to 6 digits. Per-$N$ gaps are in the constants field.

**(b) Fixed-$N$ linearity.** With $\alpha=\beta=\gamma=\delta=1$ and $q=1-\varepsilon$, use $1-q^k=1-(1-\varepsilon)^k=k\varepsilon+O(\varepsilon^2)$. Then for each fixed $n$,
$$A_n^2=\frac{(1-q^{n+1})^4}{(1-q^{2n+1})(1-q^{2n+2})}=\varepsilon^2\frac{(n+1)^4}{(2n+1)(2n+2)}+O(\varepsilon^3),\quad C_n^2=\varepsilon^2\frac{n^4}{2n(2n+1)}+O(\varepsilon^3),$$
so the off-diagonals $C_n=\varepsilon\hat c_n+O(\varepsilon^2)$ are $O(\varepsilon)$ while the diagonal $A_n^2+C_n^2$ is $O(\varepsilon^2)$. Hence $H(q)=-\varepsilon K+O(\varepsilon^2)$ with $K$ the fixed tridiagonal matrix with off-diagonals $\hat c_{n+1}=\frac{(n+1)^2}{\sqrt{2(n+1)(2n+3)}}$ and zero diagonal. Analytic perturbation theory for finite Hermitian matrices gives $E_k(q)=-\varepsilon\kappa_k+O(\varepsilon^2)$ and $m(N,q)=\varepsilon(\kappa_0-\kappa_1)+O(\varepsilon^2)$, i.e. $\nu=1$ exactly. **Verified:** at $N=8$, $m/(1-q)=2.288283,\,2.291694,\,2.294414,\,2.295024$ for $\varepsilon=10^{-3},5\cdot10^{-4},10^{-4},10^{-5}$ -- clean convergence to $\kappa(8)=2.295085$. Measured $\kappa(N)$: $1.604194$ ($N{=}4$), $1.997978$ (6), $2.295085$ (8), $2.539737$ (10), $2.750257$ (12), $3.104182$ (16). Since $\kappa(N)$ grows with $N$, the corpus's $m(q)=\min_Nm(N,q)$ is always the $N=4$ value in the fit window, so its fit is really measuring $m(4,q)=1.6042\,\varepsilon-O(\varepsilon^2)$; the $O(\varepsilon^2)$ curvature is what bends the fitted slope from $1$ down to $0.9668$.

**(c) The $N\to\infty$ constant $3/4$ [my derivation; the corpus only records $\nu\approx1$].** The fixed-$n$ expansion above is valid only for $n\varepsilon\ll1$; $\kappa(N)$ diverges slowly, so the two limits do not commute. Introduce the scaling variable $x=n\varepsilon$ and use $q^{n}=(1-\varepsilon)^{n}\to e^{-x}$. Then
$$A_n^2\to\frac{(1-e^{-x})^4}{(1-e^{-2x})^2}=\Big[\frac{1-e^{-x}}{1+e^{-x}}\Big]^2=\tanh^2(x/2),\qquad C_n^2\to\tanh^2(x/2).$$
Write $t=t(x)=\tanh(x/2)$. The matrix becomes, to leading order (all of $A_n,C_n,C_{n+1}\to t(x)$ since they differ at relative order $\varepsilon$),
$$(Hf)_n=2t^2f_n-t\,(f_{n+1}+f_{n-1})=-t\,(\Delta f)_n-2t(1-t)f_n,\qquad (\Delta f)_n=f_{n+1}+f_{n-1}-2f_n.$$
Since the relevant eigenfunctions vary on the scale $\Delta n\sim1/\varepsilon$, $(\Delta f)_n\simeq\varepsilon^2f''(x)$ and
$$H\ \simeq\ -\varepsilon^2\,t(x)\,\partial_x^2\;+\;V(x),\qquad V(x)=-2t(x)\big(1-t(x)\big).$$
$V$ is a potential well: as a function of $t\in[0,1)$, $V=2t^2-2t$ has its minimum at $t=\tfrac12$, i.e. $x_0=2\operatorname{artanh}\tfrac12=\log3\approx1.0986$, with $V(x_0)=-\tfrac12$. Hence $E_0\to-\tfrac12$ (kinetic energy is $O(\varepsilon)$). Expanding, $t'(x)=\tfrac12\operatorname{sech}^2(x/2)=\tfrac{1-t^2}{2}$, so $t'(x_0)=\tfrac{1-1/4}{2}=\tfrac38$ and
$$V(x)= -\tfrac12+2\big(t-\tfrac12\big)^2+\cdots=-\tfrac12+2\big(\tfrac38\big)^2(x-x_0)^2+\cdots=-\tfrac12+\tfrac{9}{32}(x-x_0)^2+\cdots.$$
This is the harmonic oscillator $-a\partial_x^2+b(x-x_0)^2$ with $a=\varepsilon^2t(x_0)=\varepsilon^2/2$ and $b=9/32$, whose levels are $E_k=V(x_0)+(2k+1)\sqrt{ab}$ with
$$\sqrt{ab}=\sqrt{\tfrac{\varepsilon^2}{2}\cdot\tfrac{9}{32}}=\varepsilon\sqrt{\tfrac{9}{64}}=\tfrac{3\varepsilon}{8}.$$
Therefore $E_0=-\tfrac12+\tfrac{3\varepsilon}{8}+O(\varepsilon^2)$ and
$$m_\infty=E_1-E_0=2\cdot\tfrac{3\varepsilon}{8}=\tfrac34\,\varepsilon=\tfrac34(1-q).$$
**Verification (tridiagonal eigensolver, $N=80/(1-q)$):** $m_\infty/(1-q)=0.7484909$ ($q=0.99$), $0.7492517$ ($0.995$), $0.7497021$ ($0.998$), $0.7498513$ ($0.999$), $0.7499257$ ($0.9995$). And the derived level structure: at $q=0.99$ the lowest five eigenvalues are $-0.4956182,-0.4881332,-0.4807020,-0.4733242,-0.4659999$ -- gaps $0.007485,0.007431,0.007378,0.007324$, i.e. equally spaced to within the anharmonic correction, and $E_0$ vs the predicted $-\tfrac12+\tfrac38(0.01)=-0.49625$ agrees to $6\times10^{-4}=O(\varepsilon^2)$. Both the ladder structure and the constant $3/4$ are confirmed.

**(d) Uniform gap and localisation.** The corpus's argument (`05_doob_qracah_analytic_bounds.md` §4) is that for fixed $q<1$ the recurrence coefficients converge exponentially fast ($O(q^n)$) to constants, so the semi-infinite operator is a compact perturbation of a constant-coefficient Jacobi operator; the ground state is exponentially localised near the defect at $n=0$ and enlarging $N$ past the localisation length barely moves $E_0,E_1$. **This is exactly what the numerics show**, with saturation at $N\approx30/(1-q)$: the gap is *not* monotone in $N$ (it rises then falls) but it plateaus. Note the practical failure mode: for $N\gtrsim 90$ at $q=0.95$ the Doob validity test fails because $\min\psi_0$ underflows ($\min|\psi_0|=4.7\times10^{-7}$ at $N{=}16$, $5.5\times10^{-9}$ at $N{=}48$, $1.1\times10^{-17}$ at $N{=}96$) -- this is *not* gap closure, and one should compute $E_1-E_0$ of $H$ directly at large $N$.

import numpy as np, math, numpy.linalg as la
from scipy.linalg import eigh_tridiagonal

def q_racah_jacobi_matrix(N, q, alpha=1.0, beta=1.0, gamma=1.0, delta=1.0, eps=1e-15):
    """Symmetric tridiagonal 'q-Racah shaped' matrix used by the project."""
    A = np.zeros(N+1); C = np.zeros(N+1)
    for n in range(0, N):
        num = ((1-alpha*q**(n+1))*(1-beta*delta*q**(n+1))
               *(1-gamma*q**(n+1))*(1-delta*q**(n+1)))
        den = (1-delta*q**(2*n+1))*(1-delta*q**(2*n+2))
        if abs(den) <= eps: return None
        val = num/den
        if -1e-12 < val < 0: val = 0.0
        if val < 0: return None
        A[n] = math.sqrt(val)
    A[N] = 0.0; C[0] = 0.0
    for n in range(1, N+1):
        num = (1-q**n)*(1-beta*q**n)*(1-gamma*q**n)*(1-alpha*delta*q**n)
        den = (1-delta*q**(2*n))*(1-delta*q**(2*n+1))
        if abs(den) <= eps: return None
        val = num/den
        if -1e-12 < val < 0: val = 0.0
        if val < 0: return None
        C[n] = math.sqrt(val)
    H = np.zeros((N+1, N+1))
    for n in range(N+1):
        H[n, n] = A[n]**2 + C[n]**2
        if n < N: H[n, n+1] = H[n+1, n] = -A[n]   # NB: overwritten below by C[n+1]
        if n > 0: H[n, n-1] = H[n-1, n] = -C[n]
    return H

def gap_large_N(N, q):
    """E1-E0 at large N without forming the dense matrix (needed for N >> 1000)."""
    nn = np.arange(0, N); mm = np.arange(1, N+1)
    A2 = np.zeros(N+1); C2 = np.zeros(N+1)
    A2[:N] = (1-q**(nn+1))**4/((1-q**(2*nn+1))*(1-q**(2*nn+2)))
    C2[1:] = (1-q**mm)**4/((1-q**(2*mm))*(1-q**(2*mm+1)))
    d = A2 + C2
    e = -np.sqrt(np.maximum(C2[1:], 0))
    w = eigh_tridiagonal(d, e, eigvals_only=True, select='i', select_range=(0, 1))
    return w[1]-w[0]

## 7. Non-placeholder composite transfer operator $T_q$: spectral $\Lambda$, q-6j recoupling kernel $R$, SU(2) character insertion, and a gap-inherited norm bound

`status: conditional` · `kind: construction`

### Statement

Let $H$, $\psi_0$, $D=\operatorname{diag}(\psi_0)$, $Q=-D^{-1}(H-E_0I)D$ be as above, and let $HU=U\operatorname{diag}(E_x)$, $U^\top U=I$, be the orthogonal diagonalisation of $H$.

**(a) Spectral embedding.** Set $\Lambda:=D^{-1}U$. Then the columns of $\Lambda$ are eigenvectors of $Q$ with eigenvalues $-(E_x-E_0)$, and the bulk propagator becomes *exactly diagonal* in this boundary basis:
$$Q\Lambda=\Lambda\operatorname{diag}\big(-(E_x-E_0)\big),\qquad \Lambda^\top e^{tQ}\Lambda=\operatorname{diag}\big(e^{-t(E_x-E_0)}\big)\ \ \text{(with the }\pi\text{-inner product).}$$

**(b) Recoupling kernel.** Replace the ad-hoc Gaussian boundary kernel $R(\chi,\chi')\approx e^{-|\chi-\chi'|(1-q)}$ by the actual $F$-move of $U_q(\mathfrak{su}(2))$:
$$R_{xy}=(-1)^{\sigma}\sqrt{[2x+1]_q\,[2y+1]_q}\begin{Bmatrix}a&b&x\\ c&d&y\end{Bmatrix}_q,$$
with $a,b,c,d$ fixed external spins and $x,y$ the two intermediate channels. By the quantum orthogonality relation (check C4 of the validation suite), $R$ is orthogonal: $\sum_x R_{xy}R_{xy'}=\delta_{yy'}$.

**(c) Wilson insertion.** Replace the monomial $(W_I)_{kk}=z(\chi_k)^I$ by the SU(2) character, defined by the fusion-ring recursion
$$\chi_0(X)=1,\quad\chi_{1/2}(X)=X,\quad\chi_{I+1/2}(X)=X\chi_I(X)-\chi_{I-1/2}(X),$$
and set $(W_I)_{xx}=\chi_I(X_x)$ with $X_x$ the boundary spectral coordinate.

**(d) Composite operator and norm bound.** $T_q=\Lambda^\top e^{t_{\rm bulk}Q}\Lambda\;R\;W_I$. If $R$ is orthogonal and $\Lambda$ is an isometry, then
$$\|T_q\|\le\big\|\Lambda^\top e^{t_{\rm bulk}Q}\Lambda\big\|\,\|W_I\|=\max_xe^{-t_{\rm bulk}(E_x-E_0)}\cdot\max_x|\chi_I(X_x)|,$$
and on the orthogonal complement of the constant mode,
$$\max_{x\ne0}e^{-t_{\rm bulk}(E_x-E_0)}\le e^{-t_{\rm bulk}m},\qquad m=E_1-E_0 .$$
So a bulk gap $m$ yields an explicit exponential suppression factor $e^{-t_{\rm bulk}m}$ for the composite operator, *provided* $\max_x|\chi_I(X_x)|$ does not grow with the truncation.

### Derivation

**(a).** $Q=-D^{-1}(H-E_0)D$, so $Q(D^{-1}U)=-D^{-1}(H-E_0)DD^{-1}U=-D^{-1}(H-E_0)U=-D^{-1}U\operatorname{diag}(E_x-E_0)$. Hence $\Lambda=D^{-1}U$ diagonalises $Q$ with eigenvalues $-(E_x-E_0)$ and $e^{tQ}\Lambda=\Lambda\operatorname{diag}(e^{-t(E_x-E_0)})$. This is the exact spectral representation, not an approximation; the point (made in `06_Tq_nonplaceholder_kernels_qracah.md` §1) is that once $\Lambda$ is chosen this way, *all* nontrivial structure is isolated in $RW_I$.

A caution I add: $\Lambda=D^{-1}U$ is an isometry with respect to the $\pi$-weighted inner product $\langle f,g\rangle_\pi=\sum_n\pi_nf_ng_n$ with $\pi\propto\psi_0^2$, not the Euclidean one, because $\Lambda^\top\operatorname{diag}(\psi_0^2)\Lambda=U^\top U=I$. The bound in (d) is therefore an operator-norm statement in $\ell^2(\pi)$.

**(b).** The two natural boundary bases in a fusion category are the two intermediate-coupling channels of a four-point recoupling; the change of basis is by definition the $F$-move, whose matrix elements are $\sqrt{d_xd_y}\{{}^{a\,b\,x}_{c\,d\,y}\}_q$ up to a Frobenius-Schur phase. Its orthogonality is exactly identity C4 of the validation suite:
$$\sum_X[X{+}1]_q\{{}^{A\,B\,X}_{C\,D\,E}\}_q\{{}^{A\,B\,X}_{C\,D\,E'}\}_q=\frac{\delta_{EE'}}{[E{+}1]_q}\ \Longrightarrow\ \sum_X\sqrt{[X{+}1]_q[E{+}1]_q}\{\cdot\}\cdot\sqrt{[X{+}1]_q[E'{+}1]_q}\{\cdot\}=\delta_{EE'},$$
which I verified numerically to $1.1\times10^{-15}$ over all $(A,B,C,D)\in\{0,\dots,4\}^4$ at $\theta=\pi/22$. So this construction is fully instantiable with the validated kernel: $R$ is orthogonal *as computed*, not just in principle.

**(c).** The recursion $\chi_{I+1/2}=X\chi_I-\chi_{I-1/2}$ is the SU(2) fusion rule $\tfrac12\otimes I=(I{-}\tfrac12)\oplus(I{+}\tfrac12)$ transcribed to characters; with $X=2\cos\vartheta$ it produces $\chi_I=\sin((2I{+}1)\vartheta)/\sin\vartheta$, the Chebyshev $U$ polynomials. Note this is the *same* function as $[2I+1]_q$ under $\vartheta\leftrightarrow\theta$, which is the sense in which the character insertion and the quantum dimension are the same object -- a structural consistency the ad-hoc $z^I$ monomial does not have.

**(d).** Submultiplicativity of the operator norm, plus $\|\operatorname{diag}(e^{-t(E_x-E_0)})\|=\max_xe^{-t(E_x-E_0)}$ and $\|R\|=1$ for orthogonal $R$. Restricting to $x\ne0$ (the constant/Perron mode is removed by the observable being centred) gives $e^{-tm}$.

**Prototype implementation (the placeholder version that was actually run).** For completeness, the placeholder $T_q$ from `04_qRacah_Doob_MassGap_Toy_v2.md` §7 is: $T_{\rm bulk}=\exp(t_{\rm bulk}Q)$; $R=$ row-normalised Gaussian kernel $e^{-\frac{(\chi_i-\chi_j)^2}{2\sigma_R^2}}$ on a $\chi$-grid; $W=\operatorname{diag}(e^{\kappa(\chi+\chi^{-1})})$; $\Lambda_{ij}\propto e^{-(i-c\chi_j)^2/(2\sigma_L^2)}$ column-normalised; $T_q=\Lambda^\top T_{\rm bulk}\Lambda RW$, normalised by its leading eigenvalue and $m_{\rm eff}=-\log|\lambda_1(\tilde T_q)|$. import numpy as np, numpy.linalg as la
from scipy.linalg import expm

# ---- (a) spectral embedding: makes the bulk step exactly diagonal ----
def spectral_lambda(H, psi0):
    """Lambda = D^{-1} U ; columns are eigenvectors of Q with eigenvalue -(E_x - E_0).
    Lambda^T diag(psi0^2) Lambda = I, so Lambda is an isometry in l^2(pi)."""
    E, U = la.eigh(H)
    return np.diag(1.0/psi0) @ U, E

def bulk_step_diagonal(E, t_bulk):
    return np.diag(np.exp(-t_bulk*(E - E[0])))     # == Lambda^T e^{tQ} Lambda

# ---- (b) honest recoupling kernel R from the validated q-6j kernel ----
def recoupling_R(a, b, c, d, theta, q6j, qdim, tri):
    """Orthogonal F-move matrix R_{xy} = sqrt(d_x d_y) {a b x; c d y}_q  (2j encoding)."""
    xs = [x for x in range(0, a+b+1) if tri(a, b, x) and tri(c, d, x)]
    ys = [y for y in range(0, a+c+1) if tri(a, c, y) and tri(b, d, y)]
    R = np.zeros((len(xs), len(ys)))
    for i, x in enumerate(xs):
        for j, y in enumerate(ys):
            R[i, j] = np.sqrt(qdim(x, theta)*qdim(y, theta))*q6j(a, b, x, c, d, y, theta)
    return R, xs, ys          # R R^T = I  (verified to 1.1e-15)

# ---- (c) SU(2) character insertion via the fusion recursion ----
def su2_character(twoI, X):
    """chi_I(X) by chi_{I+1/2} = X chi_I - chi_{I-1/2}; twoI = 2I."""
    cm, c0 = np.zeros_like(np.asarray(X, dtype=float)), np.ones_like(np.asarray(X, float))
    for _ in range(twoI):
        cm, c0 = c0, X*c0 - cm
    return c0

# ---- (d) the prototype (placeholder) composite operator, as actually run ----
def gaussian_kernel(x, sigma):
    dx = np.asarray(x)[:, None] - np.asarray(x)[None, :]
    return np.exp(-0.5*(dx*dx)/(sigma*sigma))
def normalize_rows(M):
    s = M.sum(axis=1, keepdims=True); s[s == 0] = 1.0; return M/s
def normalize_cols(M):
    s = M.sum(axis=0, keepdims=True); s[s == 0] = 1.0; return M/s

def build_transfer_operator(Q, chi, t_bulk=1.0, sigma_R=0.3,
                            strength=0.0, sigma_L=1.0, c=1.0):
    N = Q.shape[0]-1
    T_bulk = expm(t_bulk*Q)
    R = normalize_rows(gaussian_kernel(chi, sigma_R))
    W = np.diag(np.exp(strength*(chi + 1.0/chi)))
    i = np.arange(N+1)[:, None]
    Lam = normalize_cols(np.exp(-0.5*((i - c*chi[None, :])**2)/(sigma_L*sigma_L)))
    T = Lam.T @ T_bulk @ Lam @ R @ W
    ev = la.eigvals(T); Tn = T/ev[np.argmax(np.abs(ev))]
    mags = np.sort(np.abs(la.eigvals(Tn)))[::-1]
    lam1 = mags[1] if len(mags) > 1 else 0.0
    return (-np.log(lam1) if lam1 > 0 else np.inf), lam1

## 8. Positivity obstruction for SU(2) theta-terms in the fusion/irrep basis, and the q-6j caching strategy that follows

`status: solid` · `kind: obstruction`

### Statement

Consider a lattice SU(2) gauge theory tensor network built in the fusion/irrep (character-expansion) basis: link weights come from the character expansion of the Wilson action and are positive (Bessel coefficients $I_{2j+1}(\beta)$); gauge invariance at each vertex is imposed by intertwiners built from $3j$/$6j$ recoupling coefficients.

**Claim.** In this basis the fully gauge-invariant vertex tensor cannot be made entrywise nonnegative, at any $\theta$:
1. at $q=1$ ($\theta=0$) the Wigner $6j$ symbols are real but take **both signs** (e.g. among the 570 admissible sextuples with $2j\le4$, both signs occur; the exact value $\{\tfrac12\tfrac12 1;\tfrac12\tfrac12 1\}=+\tfrac16$ while $\{2\,2\,2;2\,2\,2\}$ and many others are negative);
2. for $q\ne1$ the $q$-$6j$ symbols acquire further sign changes (and, outside the positivity domain $(4J_{\max}+1)\theta<\pi$, purely imaginary $\Delta_q$ factors).

**Consequence.** Positive link weights times sign-indefinite intertwiners cannot be re-gauged into an entrywise-nonnegative local tensor. Therefore importance-sampling Monte Carlo on this representation is not available, and the correct computational posture is **deterministic contraction with complex tensors** (TRG / HOTRG / TNR).

**Salvage: symmetry-reduced caching.** The $6j$ symbol is invariant under the 24-element tetrahedral group (column permutations and two-column row swaps), and classically under the additional Regge symmetries, giving $\sim72$--$144$ equivalent tuples per orbit. Define a canonicalisation $\operatorname{canon}(j_1,\dots,j_6)$ mapping each sextuple to the lexicographically least element of its orbit and use it as the hash key; then a table for $J_{\max}\approx10$--$20$ fits in memory and each vertex-tensor entry becomes a lookup plus a short channel sum.

### Derivation

**Sign indefiniteness at $q=1$ is a fact, not a conjecture.** Racah's formula $\{6j\}=\Delta\Delta\Delta\Delta\sum_t(-1)^t\mathcal R(t)$ has $\Delta>0$ and $\mathcal R(t)>0$, so the sign of the symbol is the sign of an alternating sum with no positivity structure; the symbol crosses zero (Ponzano--Regge oscillation $\sim\cos(\sum_i(j_i+\tfrac12)\vartheta_i+\tfrac\pi4)/\sqrt{12\pi V}$ in the classically-allowed regime). I confirm computationally that both signs occur already at $2j\le4$.

**Why gauge invariance forces the intertwiners in.** The character expansion gives $e^{\beta\operatorname{Re}\operatorname{tr}U_p}=\sum_j c_j(\beta)\chi_j(U_p)$ with $c_j>0$. Integrating over each link variable with Haar measure produces, at each site, a projector onto the invariant subspace of the tensor product of the four (or eight in 4D) incident representations; the matrix elements of that projector *are* the recoupling coefficients. So the sign structure is welded into gauge invariance itself: there is no field redefinition inside this basis that removes it.

**Why this is the right kind of 'no'.** It is a statement about a *representation*, not about the theory: it says the fusion basis has no local positivity, hence no local sign-problem-free MC. It does not say the partition function has a sign problem in every representation. The corpus states the residual research question sharply: is there a dual set of variables (loops, surfaces, categorical data) in which the SU(2) $\theta$-phase couples to an *additive integer* that can be accumulated like a U(1) rotor winding number? If yes, phase isolation works; if no, complex TRG is the tool.

**Caching arithmetic.** The tetrahedral orbit of a generic sextuple has size 24; measured orbit sizes for special tuples are much smaller (1 for $\{1\,1\,1;1\,1\,1\}$, 3 for $\{\tfrac12\tfrac12 1;\tfrac12\tfrac12 1\}$), so a factor-24 saving is an upper bound and the true saving is orbit-size-weighted. Adding the Regge symmetries (classical only) can push the reduction toward $\sim144$. Counting the raw table size: the number of admissible sextuples grows roughly like $J_{\max}^{?}$ -- measured $47,181,570,1479,3418$ for $J_{\max}=1,1.5,2,2.5,3$, i.e. a growth factor $\approx2.3$ per half-unit of $J_{\max}$, so $J_{\max}=10$ is $O(10^7)$--$O(10^8)$ raw entries and $O(10^6)$ after canonicalisation: hundreds of MB, which is the corpus's back-of-envelope conclusion and is correct.

Best source: `SIMULATIONS/LATTICE_QCD_SU2_theta_obstruction_and_q6j_caching.md` (three byte-identical copies elsewhere).

# Canonicalisation key for a symmetry-reduced 6j / q-6j cache (2j encoding).
from itertools import permutations

def canon(tup):
    """Lexicographically least element of the tetrahedral orbit; use as cache key.
    Group: 3! column permutations, and row swaps in exactly two columns."""
    def permute_columns(t, p):
        A,B,C,D,E,F = t; cols = [(A,D),(B,E),(C,F)]
        (A2,D2),(B2,E2),(C2,F2) = (cols[p[0]], cols[p[1]], cols[p[2]])
        return (A2,B2,C2,D2,E2,F2)
    def swap2(t, w):
        A,B,C,D,E,F = t; cols = [(A,D),(B,E),(C,F)]
        i,j = w; cols[i] = cols[i][::-1]; cols[j] = cols[j][::-1]
        (A2,D2),(B2,E2),(C2,F2) = cols
        return (A2,B2,C2,D2,E2,F2)
    ops = [ (lambda x,p=p: permute_columns(x,p)) for p in permutations([0,1,2]) ] \
        + [ (lambda x,w=w: swap2(x,w))          for w in [(0,1),(0,2),(1,2)] ]
    seen, frontier = set(), [tuple(tup)]
    while frontier:
        x = frontier.pop()
        if x in seen: continue
        seen.add(x)
        for op in ops:
            y = op(x)
            if y not in seen: frontier.append(y)
    return min(seen)

_CACHE = {}
def q6j_cached(tup, theta, q6j):
    k = (canon(tup), theta)
    if k not in _CACHE: _CACHE[k] = q6j(*k[0], theta=theta)
    return _CACHE[k]

Preserving the 'no' preserves the reason the 'yes' looks the way it does.

## How these fit together
